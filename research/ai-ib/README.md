# AI 投行观点日报

中美头部投行和券商对 AI 产业链的研报观点摘编，个人跟踪用。

- 网页：https://claude.ai/artifact/VzuRGFeGgtmaWGR9JKdrsD （`index.html` 是页面源码）
- 更新：定时任务每天北京时间 9:23 跑，10 点前写好当期
- 页面不用重新发布。每期只往页面自带的数据库里写数据

## 范围

- 中资：中金、中信证券、华泰、国泰海通、中信建投、招商、广发、申万宏源、兴业等研究所
- 外资：高盛、摩根士丹利、摩根大通、美银、花旗、瑞银、野村、杰富瑞、伯恩斯坦、巴克莱、德银等
- 只看 AI 产业链：算力与半导体、云与资本开支、模型与应用、AI 融资、电力与数据中心、港股 / A 股 AI 资产、AI 对宏观的外溢

## 数据结构

`editions/<YYYY-MM-DD>`，每期一篇：

| 字段 | 说明 |
|---|---|
| `date` | 当期日期（北京时间），与文档 id 相同 |
| `no` | 期号，上一期加 1 |
| `updatedAt` | 例：`2026-10-29 09:40` |
| `headline` | 一句话本期主线 |
| `takeaways` | 3-6 条要点 |
| `divergence` | `[{topic, bull, bear}]`，多空分歧 |
| `newIds` | 本期新增研报的 id |
| `note` | 可选，说明本期的限制（比如没打开原文） |

`reports/<机构缩写>-<YYYYMMDD>-<短名>`，每篇研报一条：

| 字段 | 说明 |
|---|---|
| `date` | 研报发布日期；只知道年份时写 `2026` |
| `added` | 收录进哪一期 |
| `side` | `中资` / `外资` |
| `bank`、`team` | 机构、团队或分析师 |
| `title` | 研报标题（外资可附中文译名） |
| `stance` | `偏多` / `中性` / `谨慎` |
| `chain` | 从这些里选：算力与半导体、云与应用、资本开支与融资、宏观与外溢、港股与A股、电力与数据中心、模型与应用 |
| `core` | 核心观点，两三句 |
| `points` | 关键论据和数据 |
| `excerpt` | 原文摘录，只摘真正读到的文字 |
| `excerptNote` | 摘录出处；媒体转述必须写明 |
| `links` | `[{type, label, url}]`，type 用 原文 / 官方摘要 / 官方页面 / 转载 / 疑似原文 PDF |
| `channel` | 去哪里拿原文 |
| `verified` | 核实情况，例：「已读原文」「媒体转述，未能打开原报告」 |

## 注意

- 不编造：链接只用搜索或抓取中真实出现过的网址，摘录只用真正读到的文字
- 云端环境的网络白名单默认挡住新浪、华尔街见闻、各投行官网；放开后定时任务能直接读原文
- 页面只是观点摘编，不构成投资建议
