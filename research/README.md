## 方法论

1. **一手优先**：SEC 文件、官方新闻稿、完整视频和转录排在前面，媒体报道只当线索。
2. **标注可信度**：✅ 一手文件或多个来源一致；⚠️ 单一二手来源或口径冲突。
3. **跟着钱走**：说的话要和投的钱对照着看。英伟达投哪里，往往就是下一个瓶颈。
4. **方向和时间分开看**：尤其是马斯克，用“主张台账”记录兑现率。
5. **必须看反方**：循环融资、披露缺口、看空基金的仓位。
