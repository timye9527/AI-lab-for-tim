# 读法替换：只改配音，不改字幕。格式「原文 => 读法」，按顺序替换。
# 全大写缩写会自动拆成字母读（AI → A I），不用写在这里。

OpenAI => Open AI
ChatGPT => Chat GPT
13F => 十三 F
A股 => A 股
Token => token
泡沫.com => 泡沫点 com

# 数字按含义读：数值按数值读（3794 点），代号和日期简称逐位读（924 = 9 月 24 日）。
# 纯数字的替换只在后面没有单位时生效，「924亿」仍读「九百二十四亿」。
# 质检会把没有单位的三位以上整数列为「数字读法待确认」，确认后写在这里：逐位读的写中文数字，按数值读的也写一行固定下来。
924 => 九二四
618 => 六一八
315 => 三一五
520 => 五二零
911 => 九一一
标普500 => 标普五百
