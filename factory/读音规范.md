# 读音规范 · 配音不能在基础上出错

配音模型自己决定读音时，最常错的就是下面这些。我们的做法是**读音由我们决定，模型只负责发声**：`video/pron.py` 先把口播稿逐字转成拼音，再生成一份附加词典，让模型逐字照读。

## 容易出错的地方和处理方式

| 类型 | 典型错误 | 处理 |
|---|---|---|
| 多音字（按词） | 行长读 xíng、调研读 tiáo、重仓读 chóng、长期读 zhǎng | pypinyin 按词取音，财经常用词写进 `pron.txt` 覆盖 |
| 多音字（按语境） | 「就**得**回答」应读 děi、「传**得**最广」应读 de；「去**量** AI」应读 liáng；「**冲**着」应读 chòng；「付**了**账」应读 le；「稳固**地**」应读 de | 词典按词取音也会错，这些写成带上下文的覆盖词；读音表把「得了着量冲转还行长重调差数处为地和便降空给传」单列出来人工审 |
| 「一」「不」变调 | 一样读 yī、一间读 yī、不是读 bù | 程序按规则变调：一在四声前读 yí，在一二三声前读 yì，在数字、序数、句尾读 yī，「看一看」读轻声；不在四声前读 bú |
| 三声连读 | — | 不写进拼音，交给模型（模型训练时就是这么标的） |
| 轻声 | 的、了、着、子 | 用 5 标轻声，「地方」等常用词写进覆盖表 |
| 数字 | 10% 读成「十 percent」、2025 读成「两千零二十五」 | 程序先转汉字：年份逐位读（一九九三年）、百分比读「百分之十」、区间读「六十到七十」、千万亿前的二读「两」、「中国制造2025」逐位读 |
| 英文缩写 | AI 读成一个音「爱」、单个大写字母被当成音素符号 | 每个字母的读法都用识别模型验证过（`letters.txt`）：多数用中文音节读字母（A 读 éi、I 读 āi，播音里读缩写的方式），H、J、Q、U 交给英文引擎；L、Z 读不准，稿子里禁用。新缩写先跑 `npm run video:letters` |
| 英文单词 | 中文模型乱读 | 交给 espeak 按美式英语读；能用中文说的尽量用中文（《证券分析》而不是 Security Analysis） |
| 人名、机构 | 李录读成李路的声调、格雷厄姆的「厄」 | 人物池里的人名、机构名全部写进 `pron.txt` |
| 符号 | 「·」「《》」被读出来或吞字 | 程序直接去掉 |
| 儿化 | 模型不稳 | 口播稿不写儿化 |

## 偶发故障：重复音节、串音、吞字

模型合成有随机性，同一句话偶尔会冒出重复音节（「套利」读成「套号利」）、串音或吞字，读音表查不出来。现在每句合成后都自动回听：

- SenseVoice 和 Paraformer 两个识别模型各转写一次，转成不带声调的拼音，和稿子逐音节比对；听到的字只要有一个读音对得上就算对，所以同音字、多音字不误报。
- 不对就重读：前 3 次原样，再 2 次微调语速，最后 3 次拆成短句合成；取错得最少的一次。噪声强度从默认 1.0 降到 0.667，偶发故障更少。
- 8 次都不过，说明模型在这个词组上有硬伤，必须改写稿子（001 期改了 3 句），不允许带病出片。

## 每期必做

1. 写稿时照常写汉字、数字和英文缩写，不用管读音。
2. `npm run video -- <期目录> --no-video`：生成配音、读音表和质检报告，每句自动回听、不对就重读。
3. 打开 `episodes/<期>/读音表.md`，**先看最上面的「重点审：高风险字」**，再扫一遍逐句标注。读错的在 `video/pron.txt` 加词（带上前后一两个字，避免误伤别的句子）。
4. 回听只能发现多字、漏字、串音，**发现不了声调错误**，所以第 3 步不能省。审过确认没错的词也写进 `pron.txt`，下次就不用再审。
5. 新出现的人名、机构名、术语，第一次用就加进 `pron.txt`。

## 为什么换掉了第一版的声音

第一版用的是 Kokoro 的中文男声，模型本身的中文带口音，听感「怪」，而且多音字靠它自己猜。现在用的是 Matcha 中英双语模型（标准普通话女声，中英混读），读音完全由我们控制。

对比测试用的是同一段「刁钻」文本（多音字、英文缩写、百分比、年份、人名混在一起）：

| 模型 | 字错率 | 主要问题 |
|---|---|---|
| Matcha 中英（现用） | 0.10 → 接入读音模块后整期 0.028 → 加回听重读后整期逐音节全部通过 | 16 kHz 采样，比广播级略闷 |
| 标贝 Matcha | 0.20 | 不读英文；「行长」读 xíng cháng |
| MeloTTS 中英 | 0.20 | 「李录在」读成「以路赛」 |
| Kokoro 男声（第一版） | — | 口音、读音不可控 |

## 再往上升级

- **想要男声或更有感染力的声音**：离线开源模型里目前没有又标准又是男声的好选择。最实际的两条路：
  1. 云端配音。这个环境能连上谷歌云语音合成（普通话和英语都有高质量男声），需要一个 API Key。
  2. 用这里导出的 `subs.srt` 在剪映里换付费音色重配，读音表照样拿来逐句核对。
- 无论换成什么声音，**读音表这一步都保留**：先定读音，再配音。
