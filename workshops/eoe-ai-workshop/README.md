## 重新生成

脚本在 `build/`，有自己的 `package.json`，不影响网站和服务端的零依赖。

```bash
cd workshops/eoe-ai-workshop/build
npm install
npm run assets   # 裁切真实素材 + 绘制插画（需要 Python Pillow）
npm run deck     # 生成 PPTX + 导出演讲备注.md
python3 -I render.py ../output/动动嘴让AI把活干了.pptx <soffice 包装脚本>   # 导出 PDF 和缩略图
```

- 音乐、视频：放进 `media/`（mp3/m4a/wav、mp4/mov），`npm run deck` 时自动嵌入第 24、25 页
- 成果中台截图：放进 `materials/v2/`，文件名带「中台」，`npm run assets` 后自动接入第 12 页
- 个人照片高清版：`materials/v2/个人照片.jpg`
- 内容（每页文字和布局）：`build/build_deck.js`；演讲备注：`build/notes.js`；素材裁切：`build/prepare_assets.py`

## 设计约定（取自 EOE 会员闪光录）

- 配色：砖红 `C15145`、橙 `E77738`、奶油 `FAF3D7` / 暖白 `FFFCF5`、藏青 logo 块 `173659`、浅蓝 `B2C3F7`，点缀黄 `F5B21B`
- 元素：EOE logo 色块、黑色四角星、浅蓝椭圆、黑描边涂鸦插画；不用大面积深色背景
- 砖红整页只用于封面、反转、转场和结尾；其余页面是暖白 / 奶油底
- 辣条只在开场（2–5 页）、验收（26 页）和结尾一句话里出现
- 16:9 宽屏，字体为微软雅黑；截图都做了局部放大或高亮，表格只保留观众需要看的列
