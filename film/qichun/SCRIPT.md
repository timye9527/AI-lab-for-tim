# 《蕲水长流》脚本 v2

> 湖北蕲春 · 约 3 分钟 · 1920×1080 · 30fps · 2.35:1 电影画幅 · 中文旁白 + 中英字幕
> 画面全部由代码渲染；配音、配乐、音效也全部在本机合成，不依赖在线服务。

## 一、v2 改了什么

| v1 的问题 | v2 的做法 |
|---|---|
| 只有卫星地图一种画面，看久了单调 | 九种画面交替：3D 地图、水墨山水、干栏木屋、竹林题诗、本草线描、《本草纲目》书页、四宝书法、黄昏艾田、艾条青烟、管窑拉坯、人物卡 |
| 没有声音 | 男声旁白（Kokoro 本地合成）+ 古筝、尺八、弦乐、合唱、太鼓编曲 + 环境音效；人声出现时音乐自动压低，整片响度 −16 LUFS |
| 只讲地理和名人 | 加了风物和民俗：蕲春四宝、端午插艾、蕲春艾灸疗法（国家级非遗）、管窑制陶、蕲艾产业 |
| 时间写死 | 每段的长度由配音时长决定（`scene/timeline.js`），改一句旁白，画面自动重排 |

## 四、声音

| 层 | 做法 |
|---|---|
| 旁白 | Kokoro-82M（Apache-2.0，模型来自 npm 包 `kokoro-q8-shards`，音色 `zm_yunjian`），本机合成；用 misaki 中文注音，多音字手动校正（「为胜」读 wéi、「毛家咀」读 zuǐ）。后期：高通、暖声、去浑、提亮度、压缩、小房间混响 |
| 配乐 | `scripts/score.py` 程序编曲，D 宫五声；GeneralUser GS 音色库（可商用）：古筝、尺八、长笛、弦乐、合唱、竖琴、太鼓、定音鼓、圆号、钢琴 |
| 音效 | 全部程序合成：风、水、竹林沙沙、艾火噼啪、虫鸣、轮盘低鸣、翻书、盖章、镜头呼啸、高铁驶过 |
| 混音 | 配乐加大厅混响；人声出现时音乐自动压低；两遍 loudnorm，−16 LUFS、真峰值 −1.5 dBTP |

想要更像真人的旁白，可以照第二节的字幕请人录一条，替换 `data/audio/vo/*.wav`（同时改 `vo.json` 里的时长），再跑 `node scripts/timeline.mjs data/audio/vo/vo.json scene/voiceover.json data/audio/timeline.json && npm run audio`，画面会按新时长重排。
