# 选型速查 · 声音、画面、配乐选哪条路

> 都是实际用过的结论。G0 定方案时看这里；换模型时看「各模型要手动处理的地方」。
> 环境前提（截至 2026-10）：云端容器 4 核 CPU、15 GB 内存、**没有显卡**；网络通常只放行 npm、PyPI、GitHub，具体以环境设置为准。

## 一、声音

优先级：**真人录音 > 本人声音克隆 > 开源模型 > 云端付费音色（要钥匙或放行网络）**。

| 方案 | 用在 | 好处 | 毛病（实测） | 花费 |
|---|---|---|---|---|
| 真人录音 | 粤语管线支持；微电影、存储都建议过 | 最自然，读音最稳 | 要有人录；录完要剪、降噪 | 0 |
| **ZipVoice 克隆**（sherpa-onnx，24 kHz） | 微电影（本人声音）、存储（拿 Kokoro 男声当参考做频道音色） | 什么音色都能当参考；中英混读 | 句尾最后一个字会被截断（0.95 倍生成再加速）；**sherpa-onnx 2.0.0 会跳过全部英文词，要装 1.13.8**；全精度 16 步才像（相似度 0.78 → 0.87）；模型约 800 MB | 0 |
| **Matcha 中英**（sherpa-onnx，16 kHz） | 内容工厂 | 标准普通话女声；读音完全可控；对比测试字错率最低 | 发不出 děi；L、Z 读不准；16 kHz 偏闷；没有好男声 | 0 |
| MeloTTS 中英 | 蕲春 v3 | 韵律比 Kokoro 自然（女声） | 「一」和三声变调要逐词手写；对比测试把「李录在」读成「以路赛」 | 0 |
| Kokoro v1.1-zh | 工厂第一版、微电影第一轮、蕲春 v2、存储早期 | 男声多（几十个） | 中文有口音、「呆」、重音不对。**不要直接做成片配音**，只适合当 ZipVoice 的音色参考（sid60 沉稳 114 Hz、sid100 明亮 132 Hz） | 0 |
| edge-tts（微软在线） | 粤语管线（WanLung 男、HiuMaan / HiuGaai 女）；存储想用「云希」 | 「爆款解说腔」，粤语可用 | 云环境常拦 `speech.platform.bing.com`；非官方接口 | 0 |
| 云端付费（谷歌、火山引擎、剪映音色） | 没用过 | 质量高、男声多 | 要 API 钥匙或在剪映里手动配；读音表照样要审 | 按量，几元到几十元一条 |

**选声音的流程**：候选音色用同一段「刁钻文本」（多音字、数字、英文、人名混在一起）各合成一遍 → 语音识别打分筛掉读不准的 → 剩 2～4 个做成样片给主理人挑（微电影就是从 45 个男声里这样筛出 4 个）。

### 各模型要手动处理的地方

| 事项 | Matcha | ZipVoice | MeloTTS | Kokoro | edge-tts / 真人 |
|---|---|---|---|---|---|
| 多音字 | 程序逐字给拼音 + 覆盖表 | 覆盖表写进词典（`pronounce.tsv`） | 覆盖表写进词典 | 词典 | 改写稿子 |
| 「一」「不」变调 | 程序按规则变 | 模型自己（核对） | **逐词手写** | 不稳 | 自动 |
| 三声连读 | 交给模型 | 交给模型 | **逐词手写**（好友、也走） | 不稳 | 自动 |
| 数字 | 程序转中文 | 程序转中文（`numcn.py`） | 稿子写中文 | 自带规则不可靠 | 稿子写中文更稳 |
| 英文缩写 | 字母映射成中文音节，L、Z 禁用 | 拆开写（A I、C E O） | 少用 | 少用 | 一般能读 |
| 回听标准 | SenseVoice 逐音节 | Paraformer 听写，错误率 > 15% 报 | 打印拼音人工核 | — | 人耳 |

**换模型就重新跑一遍「刁钻文本」**，确认上表这一列，不要沿用上一个模型的结论。

## 二、画面

| 路线 | 用在 | 适合 | 代价 |
|---|---|---|---|
| HTML / CSS 版式 + 无头 Chromium 逐帧截图 + ffmpeg | 内容工厂、存储、粤语 | 金句、数据卡、图表、解说类；改字快 | 0 元；画面没变的帧直接复用最省时 |
| Canvas 程序化动画 | 短片、微电影 | 角色动画、喜剧节奏卡到帧；角色 100% 一致 | 0 元；角色和场景要写代码，工期按天 |
| three.js 3D（真实地形 + 建筑） | 蕲春 | 城市 / 地理宣传片 | 没显卡只能软件渲染，**一个画幅 1～1.5 小时**；数据下载 340 MB |
| 交互图解 + 录屏 | DRAM（anatomy 技能） | 讲结构、讲原理的科普 | 需要剪辑配音，管线没打通 |
| AI 文生图插画 + 代码叠字 | 粤语 sketch 场景 | 有插画感的财经解说 | 图里不能有字（AI 写错字、logo 有商标风险）；要主理人自己出图 |
| AI 视频生成（可灵、即梦） | 只评估过，没用 | 想要 3D 电影质感 | 60 秒片约 200～500 元（抽卡 50～80 次，价格以官网为准）；角色会漂；中文字写错；本环境调不了，要主理人账号 |
| 静态图推拉 | 不用 | — | 观感像幻灯片 |

## 三、配乐和音效

| 路线 | 用在 | 注意 |
|---|---|---|
| 代码合成（`synth.js`、`mix.py`、`score.py` + GeneralUser GS 音色库） | 短片、微电影、存储、蕲春 | 免费、可商用；音色朴素；**混音前单独听配乐**（存储的电波杂音就是相位 bug） |
| 授权曲库 / 剪映自带音乐 | 建议过 | 人声为主，配乐明显压低（内容工厂建议 -25 dB 左右），说话时自动再压低 |
| 流行歌原曲 | **不用** | 没授权，不能用录音、旋律、歌词；要同样感觉就原创同风格 |

响度统一 -14 LUFS、真峰值 ≤ -1 dBTP，导出 48 kHz aac。

## 四、对口型 / 主播

| 方案 | 说明 |
|---|---|
| 张嘴 / 闭嘴两张图按音量切换 | 粤语管线在用；0 元，够用 |
| 商用（HeyGen、Hedra） | 效果好，按分钟收费 |
| 开源（LivePortrait、MuseTalk、LatentSync） | **要显卡**，本环境跑不动 |
