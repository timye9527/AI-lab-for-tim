# 视频质检

成片的底线：**不能有普通人一听就听出来、一看就看出来的错**。自动检查能抓的全部清零才出片；抓不到的（声调、语境）按清单人工过。

## 流程

1. **跑质检，不出片**
   ```bash
   npm run video -- factory/episodes/<期> --no-video
   ```
   生成 `episodes/<期>/质检报告.md` 和 `读音表.md`。有「必须修」的项时命令以非零退出，正式出片也会被拦住。

2. **按问题类型修**（见下表），改完重跑第 1 步，直到「自动检查全部通过，0 项提醒」。只重配改过的句子，很快。

3. **人工审读音（按语境，不按字）**：打开 `读音表.md`。
   - 「需要拍板」：争议读音（词典读法和日常听感可能不一致，例如「总得」），**列给用户决定**，不要自己定。
   - 「重点审」：每一处都读出整句、想清楚这个字在句子里的意思，再对照 `factory/读音规范.md` 的「多音字语境规则」定读音。标了「按语境应读 X」的是规则命中，基本就是错的。
   - 读错：在 `factory/video/pron.txt` 加带上下文的词（如「就得 jiu4 dei3」）。
   - 读对：也把这个词写进 `pron.txt` 末尾「人工审过、确认无误的词」，让清单只剩新出现的字。

4. **出片**：`npm run video -- factory/episodes/<期>`。质检没过会拒绝出片；**不要用 `--force` 绕过**，除非用户明确要求。

5. **成片复核**（自动）：出片后从成片里逐句再听一遍（只用 SenseVoice，比合成阶段更严），有没听对的句子就改写后重出；再抽 8～9 帧拼图看版面和动画。

6. **交付时告诉用户**：质检结果（通过几句、重读几句、改写了哪几句以及原因）、人工清单里还需要用户自己做的事。

## 问题类型 → 修法

| 报告里的问题 | 原因 | 修法 |
|---|---|---|
| 配音 ✗「多出某音」「听成了」重读 8 次仍不过 | 模型在这个词组上有硬伤（重复音节、串音） | **改写这句**：换同义词、拆短句、去掉叠字（「一层一层」→ 换说法）。不要硬留 |
| 配音 ✗「没读出来」 | 吞字 | 改写，避开轻声堆叠；把关键字放到重读位置 |
| 配音 △ 轻声虚词读得轻 | 「着」「的」等被读得太轻 | 能改就改（「连着一间」→「就是一间」），零提醒才算干净 |
| 稿子报错「字母 X 配音读不准」 | L、Z 这个模型读不准 | 改写成中文（LLM → 大语言模型） |
| 新缩写 | 字母读法没验证过 | `npm run video:letters -- <缩写>`，3/3 通过再用；不过就在 `letters.txt` 加整词读法再验 |
| 读音表里声调不对 | 多音字按词取音也会错 | `pron.txt` 加带上下文的词 |
| 画面 ✗ 孤字（最后一行只剩一个字） | 文字刚好多出一个字 | 缩短文字，不要改字号硬塞 |
| 画面 ✗ 越界、压字幕区、顶到章节栏 | 一页内容太多 | 拆页或删元素 |
| 字幕 ✗ 超过一行 | 句子没有标点可断 | 口播稿里加逗号 |
| 合规 ✗ 高危词 | 见 `scripts/lint-words.mjs` | 改写；免责声明必须口播 |

## 已知易错清单（每期写稿就避开）

完整记录在 `factory/错误档案.md`，开工前扫一遍；这次犯了新错误，追加到档案并更新这里。

- **得**：必须义读 děi（就得、还得、你得），补语读轻声 de（传得、涨得、看得懂），得到读 dé。**「总得」是争议读音**：词典读 zǒng děi，主理人听感偏 de，每期都要请主理人拍板。
- **了**：「到不了」读 liǎo，「付了账」读 le。
- **量**：动词「去量」读 liáng。**冲着**读 chòng。**运转**读 zhuǎn。**稳固地**的「地」读 de。**视频为**的「为」读 wéi。
- **一、不**：程序自动变调；「看一看」读轻声。
- **数字**：年份逐位读（一九九三年），「中国制造2025」逐位读，其他四位数按数值读；百分比读「百分之……」。
- **英文缩写**：AI 读 éi āi，用中文音节读字母；IPO、MBA 逐字母读；L、Z 禁用。英文单词尽量换成中文（《证券分析》而不是 Security Analysis）。
- **模型硬伤词组**（001 期实测，改写过）：「量世界秩序」（秩序被听成继续）、「整场传得最广」（多出一音）、「拿这几条原则」（吞「几」）、「一层一层」（重复音节）、「其实是在缩水」（重复音节，重读后过了）。
