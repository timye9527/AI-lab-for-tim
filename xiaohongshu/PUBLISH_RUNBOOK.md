# 发布流程（在已登录小红书的那台电脑上执行）

**当前模式：只存草稿。** 委托方要求由本机Claude把E01-v4填好并保存为草稿，最终“发布”由委托方本人在手机端点击。本机Claude不点“发布”。

云端会话访问不到你本机的 Chrome，也连不上小红书。浏览器自动发布要在**登录了小红书的那台电脑**上，用能操作浏览器的 Claude 会话（如 Claude Code 桌面版/CLI + Chrome 浏览器集成）来做。

## 准备

1. 在那台电脑上拉取本仓库分支 `claude/xiaohongshu-e01-production-gd18aa`，进入 `xiaohongshu/`。
2. 把素材包 `E01-v4_上传素材包.zip` 里的 `upload/` 放回 `review/E01-v4/upload/`（图片不在公开仓库里）。
3. 用本机 Claude 打开本目录，说：“按 PUBLISH_RUNBOOK.md 发布 E01-v4”。

## 执行步骤（给本机 Claude）

1. 运行 `python3 tools/prepublish.py E01-v4`。版本未批准、已发布过或缺图时会停止，不要绕过。
2. 把脚本输出（标题、正文、Tag、图片顺序）完整发给委托方，等待回复“确认发布”。没有这句就不点发布。
3. 在已登录的 Chrome 打开 https://creator.xiaohongshu.com ，进入“发布笔记 → 上传图文”。
   - 按 01→06 顺序上传图片，确认缩略顺序与第1步一致。
   - 标题、正文从 `review/E01-v4/post.md` 原样粘贴；Tag 用页面的话题功能逐个添加：读书、阅读方法、表达能力、罗翔、自我提升。
   - 不改账号资料、不设置定时以外的其他选项、不删旧帖、不互动、不群发。
4. 截图编辑页，与第1步核对；点“暂存/存草稿”（不是“发布”），只存一次。然后确认草稿能在手机App的草稿箱看到；若网页草稿只存在本浏览器、手机看不到，告诉委托方改用手机直接上传素材包。
   （仅当委托方另行明确要求代发时，才点“发布”，且只点一次。）
5. 在“笔记管理”里确认新笔记出现、状态正常（审核中/已发布），复制笔记链接。
   - 若页面报错或不确定是否发出：**先去笔记管理查**，确认没有再重试，防止重复发布。
6. 更新 `progress.json`：`published_posts` 加入 `{"id":"E01-v4","published_at":"…","post_url":"…","status":"…"}`；`review/metrics.json` 填 `published_at` 与 `post_url`；该日为 Day1。提交并推送。
7. 24小时、7天后在创作者后台读取曝光、阅读、点赞、收藏、评论、主页访问、单篇新增关注，读不到的写 null，不用账户总粉丝差冒充单篇。

## 不能做

- 不输入、保存或导出密码/Cookie；登录与身份验证由委托方完成。
- 不刷粉、不群发、不删旧帖、不改账号资料。
- 未获“确认发布”或 prepublish 报停时不发布。
