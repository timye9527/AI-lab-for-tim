# 给 Codex 的任务（可直接粘贴为定时任务的提示词）

> 每次触发都从头执行下面的流程。流程是幂等的：先读 progress.json 判断走到哪一步，做完一步就写回，重复触发不会重复存草稿或重复发布。

---

你在协助运营一个小红书成长与表达账号（起点280粉，21天9期试验，目标向1000粉推进，不承诺结果）。工作目录是本交接文件夹。先读 `progress.json`、`PLAYBOOK.md`、`PUBLISH_RUNBOOK.md`、`TASKS.md`，按以下顺序只做**当前该做的一步**，做完更新 `progress.json`（`updated_at`、`completed`、`next_action`、`blockers`），然后用一两句话告诉委托方结果。

**第0步：环境**
- 运行 `python3 tools/prepublish.py E01-v4`。缺 Pillow/numpy 时用当前 Python 环境安装（只装这两个），不改系统配置。
- 浏览器使用你这边已登录小红书的会话。若发现未登录、需要验证码或扫码，停下并告诉委托方，不要尝试绕过。

**第1步：E01-v4 存草稿**（`xhs_drafts` 里没有 E01-v4 时执行）
- E01-v4 已获委托方批准存草稿，不需要再次确认。图片、标题、正文、Tag 一律按 `review/E01-v4/` 原样，不改字、不换图、不加话。
- 打开 https://creator.xiaohongshu.com → 发布笔记 → 上传图文：按 `review/E01-v4/upload/` 的 01→06 顺序上传；标题、正文从 `review/E01-v4/post.md` 复制；话题逐个添加：读书、阅读方法、表达能力、罗翔、自我提升。
- 若发布页有“内容含AI合成”之类的声明开关，保持默认，不自行勾选或取消。
- 点“暂存/存草稿”，**不点发布**，只存一次。存完到草稿箱确认存在，截图留证（截图不含账号隐私以外的无关信息）。
- 写入 `progress.json` 的 `xhs_drafts`：`{"id":"E01-v4","saved_at":"…","where":"网页创作者后台草稿箱","verified":true}`。
- 告诉委托方：“E01-v4 已在草稿箱，手机端可打开发布。”若网页草稿在手机App看不到，如实告诉委托方，并说明素材包可直接在手机上传。

**第2步：发现已发布**（存过草稿、`published_posts` 里还没有该篇时执行）
- 到创作者后台“笔记管理”查看该篇是否已由委托方发布。已发布：记录链接、发布时间、状态到 `published_posts` 和 `review/metrics.json`，该日为 Day1。未发布：什么都不做，等下次。

**第3步：数据**（已发布满24小时/7天且对应字段为空时执行）
- 从创作者后台读取曝光、阅读（观看）、点赞、收藏、评论、主页访问、单篇新增关注，写入 `review/metrics.json` 的 `h24` / `d7`。读不到写 null。账号总粉丝数单独记，不能当作单篇新增关注。
- Day7、14、21 写复盘到 `review/retro-dayN.md`：用同龄期数据判断问题在打开（封面标题）、收藏（内容价值）还是关注（主页转化），只依据真实数据，下一期只改一个变量。

**第4步：下一期制作**（未发布的成品 + 草稿合计少于2篇时执行，每次最多做1篇）
- 按 `TASKS.md` 的21天计划取下一个题目，遵守 `PLAYBOOK.md`（冷启动不挂账号名、图上不写说明小字、文案轻；但引号内只放可逐字核对的原话，自己的观点用“我的理解”区分，不编造经历和数据）。
- 版式沿用黑白＋荧光黄绿＋少量蓝色杂志拼贴风。文字页优先用 `tools/card.py text SPEC.json --style-ref assets/practice.png --no-brand` 本地出图（参照 `review/E01-v4/specs/`），不要逐页生成图片、不要无上限返工。
- 有原视频的题目：原生字幕拼图用 `skill/scripts/native_subtitle_stitch.py`（每张最多7个严格递增时间点，保留烧录字幕原像素），再用 `tools/card.py native … --no-brand` 放进3:4画布。新人物必须找到原始视频/讲座核对原话，不用网传金句。
- 产出放 `review/E0X-v1/`：upload/ 图片、post.md（标题≤20字、正文≤1000字、3–5个Tag）、preview_phone.jpg、QC.md（来源、取帧时间点、语义与错字检查）。用 `tools/glyph_check.py` 查缺字，逐张打开看图。
- 新一期**不直接存草稿**：先把预览图和完整文案发给委托方，等委托方回复确认该版本后，下次运行再按第1步流程存草稿。

**任何时候都不做**
- 不点“发布”（除非委托方针对某个具体版本明确说“直接发”）；不删旧帖、不改账号资料、不互动刷量、不群发、不买服务。
- 不输入、保存、导出密码或 Cookie；不把本地路径、登录信息写进帖子或发给外部服务。
- 不编造数据、效果或经历。做不到的步骤如实写进 `blockers`。
