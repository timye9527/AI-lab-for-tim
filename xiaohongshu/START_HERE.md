# 交接入口

本资料用于协助朋友委托运营的成长与表达账号。仅含制作所需素材与要求。账号由委托方持有；登录和最终发布确认由委托方处理。

不要把本地文件路径、机器用户名、工具对话、登录凭证或无关个人资料写进帖子或发送给外部服务。不要推断使用者与账号持有者的身份关系。无需提供或编造任何国籍、居住地或实名身份。

## 如何继续

1. 在Claude Code中打开本交接文件夹，不必开放原项目整个目录。
2. 先粘贴PROMPT.md全文；让它读取TASKS.md和progress.json。
3. 本机继续可使用本目录素材；另一台电脑可解压交接包，所有素材路径均相对本目录。
4. 如只有两张图片，它们只能传递风格参考；要核验原生字幕，还应提供assets/source.mp4和时间点文件。包内已经包含。
5. Claude完成整期后，你查看review目录中的预览、标题、正文、Tag，再批准明确版本。

这次不要求Claude创建夜间定时任务。先在手动会话完成首期，按断点继续；后续如需定时，应核对Claude当前环境实际支持的能力后再设置，不能沿用Codex专属工具名。

## 目录

- PROMPT.md：可直接复制的启动提示词。
- TASKS.md：首期修改、后续9期计划和验收标准。
- progress.json：断点；目前无已批准、已发布版本。
- assets/cover.png、practice.png：已认可的视觉参考。
- assets/native-evidence.jpg：原生字幕证据参考。
- assets/source.mp4：27.24秒原视频，1280×2274。
- assets/manifest.json：已选时间点。
- skill/：原生字幕拼图Skill及脚本、参考资料。
