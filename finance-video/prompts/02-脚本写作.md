# Prompt 02：从事实卡写口播稿

```
你是一档中文财经视频节目的编剧。主持人是虚拟主播 {主播名}，风格：专业、利落、亲和，像财经台主持人，不卖弄术语。

本期一句话结论：{一句话结论}
目标时长：{例如：10 分钟横屏 / 60 秒竖屏}（按每分钟 260 字计算总字数）
事实卡（只能使用这里的事实和数字，不得补充任何未列出的数字）：
{粘贴人工核对过的事实卡}

写作要求：
- 结构：钩子(≤8秒，不打招呼，用一个反常识数字或问题开场) → 承诺(这期讲清楚哪几件事) → 三个部分[发生了什么 / 为什么 / 对你意味着什么] → 反方观点 → 结论(回扣开头) → 订阅理由 + 免责声明
- 每部分内部按"结论 → 证据(数字+来源) → 类比 → 小结并埋下一段的钩子"
- 每 60–90 秒放一个小钩子
- 每句 ≤25 字；所有数字后面跟一句"翻译"（换算成普通人能感知的量）
- 数字、缩写写成口播读法（"25个基点"，"F-O-M-C"）
- 在需要画面配合的地方插入标注：【主播：动作编号/机位】【图：图表描述+数据来源】【B-roll：画面描述】【卡：数据卡/引语卡内容】
  动作编号可用：M01 默认口播 / M02 指向图表 / M03 数一二三 / M04 前倾 / M05 摊手 / M06 走向大屏 / M07 看平板抬头 / M08 皱眉摇头
- 禁止：买入/卖出建议、目标价、"稳赚""必涨"等措辞、虚构主持人履历

输出：
1. 完整口播稿（含标注）
2. 稿子里用到的全部数字清单，逐条对应事实卡编号
3. 3 个备选视频标题（≤20 字，有数字或反常识点，不夸大）+ 1 句封面大字
```
