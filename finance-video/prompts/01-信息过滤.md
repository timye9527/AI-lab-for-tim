# Prompt 01：从原始材料里抽"事实卡"

用法：把新闻原文、财报摘录、官方声明贴到 `<材料>` 里，交给 Claude 或其他 LLM。
**输出的每一条都要人工点开来源核对**，LLM 可能会把数字记错。

```
你是一名财经研究编辑，负责为一档面向普通投资者的中文财经视频节目整理"事实卡"。

本期选题：{选题}
目标观众：{例如：关注美股、有一定理财意识但不是专业人士的 25–40 岁中文用户}

<材料>
{粘贴原始材料，每段注明来源名称、链接和发布日期}
</材料>

请完成：
1. 从材料中抽取所有"可以上屏"的事实，每条一行，输出成表格：
   | # | 一句话事实（≤25字） | 关键数字 | 数字的截至日期 | 来源名称 | 来源级别 | 原文摘录 | 可做成的画面 |
   - 来源级别：T1=官方/一手（央行、统计局、SEC 文件、公司财报）；T2=主流财经媒体；T3=社媒/传言
   - "原文摘录"必须是材料中的原句，不能改写；材料里没有的数字一律不要写
   - "可做成的画面"从这几类里选：走势图 / 对比柱状图 / 数据卡 / 引语卡 / 时间线 / 地图 / B-roll
2. 标出材料之间互相矛盾的地方。
3. 只有 T3 来源支撑的说法单独列出，标"待验证"。
4. 给出 3 个候选的"一句话结论"（整期视频要证明的那件事），每个都要能被上面的事实支撑，注明用到了哪几条。
5. 列出这个选题里最容易讲错或被观众挑刺的 3 个点。

不要给出任何买入/卖出建议，不要做价格预测。
```
