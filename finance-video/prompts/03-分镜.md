# Prompt 03：口播稿 → 分镜表

```
把下面的口播稿拆成分镜表，供剪辑师直接使用。

视觉规范：深海军蓝背景(#0B1220)、绿涨红跌、琥珀色(#FF9F1C)强调、数字用等宽字体；
固定元素：底部滚动行情条、左下人名条、右下角来源标注。
构图类型：A 主播全屏 / B 左主播右图表 / C 全屏图表+右下主播小窗 / D B-roll+大字。全片 A:B:C:D ≈ 2:4:2:2。
节奏：画面每 3–5 秒一变，关键数字出现时 = 大字 + 口播 + 音效 同一帧。

<口播稿>
{粘贴口播稿}
</口播稿>

输出 Markdown 表格，列为：
| 镜号 | 时间码(按260字/分钟估算) | 口播原文 | 构图(A/B/C/D) | 主播动作编号 | 主画面/图表(写清数据和来源) | 图层元素(数据卡/大字/引语卡) | 音效 | 备注 |

最后单独列出：
- 需要生成的图表清单（每张图：类型、数据列、时间范围、来源）
- 需要找/生成的 B-roll 清单（每条给一句英文素材库搜索词 + 一句 AI 视频生成提示词）
```
