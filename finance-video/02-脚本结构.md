# 02 脚本结构

## 1. 时长与字数

- 中文口播语速 **250–280 字/分钟**（财经类偏快，显得干练）。
- 横屏长视频 8–12 分钟 ≈ 2000–3000 字；竖屏短视频 45–60 秒 ≈ 200–260 字。
- 一个长视频可以拆出 3–5 条短视频（每个"段落"本身就是一条 Short）。

## 2. 长视频骨架（以 10 分钟为例）

| 时间 | 段落 | 写法 | 主播出镜？ |
|---|---|---|---|
| 0:00–0:08 | **钩子** | 一个反常识数字或问题。不打招呼，不说"大家好" | 是（近景，直视镜头） |
| 0:08–0:30 | **承诺** | "这期讲清楚三件事：…，最后一点直接关系到你的…" | 是 → 切画面 |
| 0:30–0:45 | 片头 | 2–3 秒 logo + 一句话标题卡 | 否 |
| 0:45–3:00 | **第一部分：发生了什么** | 事实 → 数据图 → 一句话小结 | 30% |
| 3:00–6:00 | **第二部分：为什么** | 机制解释 + 类比（"就像…"）+ 历史对比 | 30% |
| 6:00–8:00 | **第三部分：对你意味着什么** | 分人群：存款的人 / 有房贷的人 / 持有美股的人 | 40% |
| 8:00–9:00 | **反方观点** | "但也有人认为…"（增加可信度） | 是 |
| 9:00–9:40 | **结论** | 回扣开头的一句话结论 + 接下来要盯的 2–3 个数据/日期 | 是 |
| 9:40–10:00 | CTA + 免责声明 | 订阅理由 + "不构成投资建议" | 是 |

## 3. 每一段内部的"四拍"

```
结论（一句话）→ 证据（数字 + 来源上屏）→ 类比/画面 → 小结（为下一段埋钩子）
```

例：
> **结论**：这次降息，对你的房贷可能没那么大帮助。
> **证据**：因为 30 年期房贷利率跟的是 10 年期美债，不是联邦基金利率。（画面：两条线叠在一起的走势图，来源：FRED）
> **类比**：美联储能调的是"短期的水龙头"，房贷看的是"长期的水位"。
> **小结**：那长期水位是谁决定的？这就要说到第二件事——

## 4. 句子层面的规则

- 每句话不超过 25 个字，主播好念、字幕好排。
- 数字要"翻译"：不说"2.4 万亿美元"就停，接一句"差不多是…的 X 倍"。
- 每 60–90 秒一个"小钩子"："但这还不是最反常的"、"真正的问题在后面"。
- 不用"建议买入/卖出""稳赚""必涨"这类词。
- 给剪辑留口子：在稿子里用 `【图：…】【B-roll：…】【主播：…】` 标注，分镜阶段直接用。

## 5. 竖屏短视频骨架（45–60 秒）

| 秒数 | 内容 |
|---|---|
| 0–2 | 大字数字 + 主播一句话（"美联储刚刚又降息了，但你的房贷可能一分都不会少"） |
| 2–15 | 1 个最关键的事实 + 1 张图 |
| 15–40 | 机制解释，画面每 2–3 秒一切 |
| 40–55 | 对你意味着什么（一句话） |
| 55–60 | "完整版在主页" / 下一个问题当钩子 |

写稿可以直接用 [`prompts/02-脚本写作.md`](prompts/02-脚本写作.md)，输入是第 01 步做好的事实卡。
