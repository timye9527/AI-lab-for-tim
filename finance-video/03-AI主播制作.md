# 03 AI 主播制作

目标：一个**每期都长得一样**、看起来像财经台主播、能自然说话和做手势的虚拟人。
难点不在"生成一个美女"，而在**一致性**和**口型/手部不穿帮**。

> 工具迭代很快，下面列的是常见选项，用之前先确认当前版本、价格和商用授权条款。

## 1. 人设卡（先定，再生图）

把下面这张卡写死，之后所有提示词都从这里取，保证每期一致：

```yaml
名字: Lena（虚构人物，不对应任何真人）
年龄感: 25–28 岁
定位: 财经频道主持人，专业、利落、亲和，不走性感路线
脸部: 鹅蛋脸，自然妆，深棕色及肩直发 / 低马尾
服装库:
  - 海军蓝西装外套 + 白色真丝衬衫（主造型）
  - 驼色高领毛衣（周末/轻松选题）
  - 黑色西装套装（重大事件：FOMC、暴跌）
配饰: 细金耳钉，简单手表（配饰越少，视频里闪烁越少）
场景: 虚拟演播室——身后是纽约天际线落地窗 + 侧面多屏行情墙
机位: A 机位 中近景（胸部以上）直视；B 机位 侧 45° 半身；C 机位 站立全身（走到大屏前讲解）
声音: 25 岁左右女声，语速偏快，吐字清楚，带一点笑意
```

为什么"专业不性感"：财经观众的核心诉求是信任。颜值负责让人点进来，**专业感负责让人留下来**；
而且太擦边的形象在 YouTube 上会被限流/限制广告。

## 2. 定妆照与一致性

**第一步：出定妆照**
- 用生图模型（Midjourney、Flux、GPT-Image、即梦、Nano Banana 一类）按人设卡出 50–100 张，挑 1 张作为"母版脸"。
- 提示词模板见 [`prompts/04-AI主播形象.md`](prompts/04-AI主播形象.md)。

**第二步：做角色设定图（reference sheet）**
用母版脸生成：正脸 / 3/4 侧 / 侧脸 / 半身 / 全身 / 三套服装，各 3–5 张。

**第三步：锁定一致性（三选一，从易到难）**

| 方法 | 做法 | 适合 |
|---|---|---|
| 角色参考 | 在支持"角色参考/主体参考"的工具里每次都喂母版图 | 起步阶段，最快 |
| 训练 LoRA | 用 20–30 张设定图在 Flux/SDXL 上训一个人物 LoRA | 要长期做、要大量出图 |
| 数字人平台建模 | 在 HeyGen 等平台用定妆视频建一个固定 avatar | 主要做口播，追求稳定 |

## 3. 让她说话：TTS + 对口型

```
口播稿 → TTS 生成音频（分段，每段 ≤ 60 秒）→ 对口型生成视频 → 剪辑
```

**声音（TTS）**
- 商用：ElevenLabs、MiniMax 语音、Fish Audio、火山引擎/豆包语音等；开源：CosyVoice、F5-TTS 一类。
- 固定一个声音 ID，每期复用。
- 数字、英文缩写提前写成读法：`FOMC` → "F-O-M-C"，`25bp` → "25 个基点"，`2.4T` → "2.4 万亿"。

**对口型 / 数字人**

| 路线 | 工具举例 | 优点 | 缺点 |
|---|---|---|---|
| 一体化数字人平台 | HeyGen、Synthesia | 稳定、口型准、批量快 | 动作偏少，像播音员 |
| 图片 + 音频 → 说话视频 | Hedra、OmniHuman/即梦数字人、可灵对口型 | 一张定妆照就能驱动，表情自然 | 长段落容易漂移，要分段 |
| 视频 + 音频 → 改口型 | Sync.so、LatentSync、MuseTalk（开源） | 先做好带动作的视频，再改嘴 | 需要先有动作视频 |

**推荐组合**：A 机位口播用"图片 + 音频"或数字人平台（稳）；需要动作的镜头用下一节的方法，再用"视频改口型"补嘴型。

## 4. 让她动起来：动作库

财经主播常用的动作就那么几种。**一次性生成一个动作库，每期复用**，不要每期现做：

| 编号 | 动作 | 用在哪 | 时长 |
|---|---|---|---|
| M01 | 直视镜头，轻微点头，自然眨眼 | 默认口播底片 | 8–10s |
| M02 | 右手抬起指向画面右侧（指向图表） | "看这张图" | 4–5s |
| M03 | 伸出手指数"一、二、三" | "三件事" | 5s |
| M04 | 身体前倾，压低声音的表情 | 讲反常识点、钩子 | 4s |
| M05 | 微笑摊手 | 反方观点、"但是" | 4s |
| M06 | 走向身后大屏，侧身讲解 | C 机位，段落开头 | 6–8s |
| M07 | 低头看平板/文件，再抬头看镜头 | 段落转场 | 4s |
| M08 | 皱眉、摇头 | 讲风险、暴跌 | 3s |

做法：定妆照 → **图生视频**（可灵、Veo、海螺、Seedance、Runway 一类），提示词写清楚动作 + "固定机位、演播室灯光、表情自然"，
每个动作抽 5–10 次挑最好的。动作提示词见 [`prompts/04-AI主播形象.md`](prompts/04-AI主播形象.md)。

## 5. 质检清单（逐条看，不合格重抽）

- [ ] 手：手指数量、手指有没有融在一起（手势镜头尽量短，2–4 秒）
- [ ] 牙齿和嘴型：张嘴时牙齿不糊，"b/p/m"闭嘴音嘴唇真的闭上
- [ ] 眼睛：每 3–5 秒眨一次眼，视线不乱飘
- [ ] 配饰/发丝：耳环、发丝没有闪烁或凭空出现
- [ ] 背景：身后屏幕上的"数字"如果是乱码，用后期盖一层真实图表，或者把背景虚化
- [ ] 一致性：跟母版脸并排对比，发型、痣、眉形一致

## 6. 主播在画面里的用法

- 主播只占 30–40% 时长。**剩下的时间都是图表和 B-roll**——这既是节奏需要，也能把 AI 穿帮风险降到最低。
- 常用构图：
  - 全屏口播（钩子、结论）
  - **左主播 + 右图表**（画中画，主播抠像后放左 1/3，右侧放图表）——这是"华尔街感"最强的构图
  - 主播缩到右下角小窗 + 全屏图表（讲数据细节时）
- 抠像：生成时就用纯色/简单背景，后期用剪映"智能抠像"或达芬奇 Magic Mask，再合成到统一的虚拟演播室背景里，这样每期背景完全一致。
