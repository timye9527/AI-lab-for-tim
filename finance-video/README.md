# 财经视频逆向工程：AI 美女主播 × 扎实信息 × 华尔街画面

目标：把「年轻女主播出镜 + 扎实的信息 + 专业的财经画面（华尔街风格）」这类视频，拆成一条可复制的生产线。
不做完整成片，重点是**选题/信息过滤**和**怎么做出这个画面效果**。

## 这类视频为什么能火（拆解公式）

```
留存 = 钩子(反常识数字) × 信息密度(每 20 秒一个新事实) × 画面切换(每 3–5 秒一次) × 人设信任(固定主播)
```

| 要素 | 观众感受 | 实际在做什么 |
|---|---|---|
| 年轻女主播出镜 | 有人在"跟我说话"，降低财经的门槛 | 占屏 30–40%，只出现在开头、转折和结论 |
| 扎实的信息 | "这个号说的东西有出处" | 每个数字可溯源到一手数据，屏幕上标来源 |
| 华尔街风格画面 | "专业、贵、像彭博" | 深色底 + 涨绿跌红 + 等宽数字 + 交易大厅 B-roll + 动态图表 |
| 节奏 | 停不下来 | 画面 3–5 秒一切，信息 20 秒一推进，60–90 秒一个小高潮 |

## 快速上手

```bash
pip install matplotlib numpy pillow   # 系统里需要 ffmpeg

# 选题打分：按评分表给候选选题排序
python3 tools/topic_score.py examples/topics.csv

# 10 秒开头钩子样片（CRT 质感 + 故障大字 + 双语字幕 + 竖排免责声明）
python3 tools/hook_demo.py --out out/hook_10s.mp4 [--host-image host.png]

# 生成一段华尔街风格的动态折线图（竖屏 9:16，用于 Shorts/抖音）
python3 tools/wallst_chart.py examples/sample_series.csv \
  --title "10 年期美债收益率" --unit "%" --source "示例数据，非真实行情" \
  --out out/chart.mp4 --vertical
```
