# 04 华尔街风格画面与剪辑

"华尔街感"不是靠某一个素材，而是一套**统一的视觉语言**。定下来之后，每期只换内容不换样式。

## 1. 视觉规范（Style Guide）

**配色**

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#0B1220`（深海军蓝）/ `#05070D`（近黑） | 终端风，比纯黑更有质感 |
| 上涨 | `#00C853` | 美股习惯**绿涨红跌** |
| 下跌 | `#FF3B30` | |
| 强调 | `#FF9F1C`（琥珀/终端橙） | 关键数字、高亮框、标题下划线 |
| 正文 | `#E6EDF3` | |
| 次要 | `#7D8590` | 来源、坐标轴 |

> 涨跌颜色要全频道统一。如果观众主要是 A 股用户（红涨绿跌），在第一期或固定位置说明一次"本频道按美股习惯：绿涨红跌"，或者干脆在图上写 ▲▼ 符号。

**字体**
- 标题：思源黑体 Heavy / 阿里巴巴普惠体 Bold
- 数字：**等宽字体**（JetBrains Mono、Roboto Mono、IBM Plex Mono）——这是"终端感"的关键
- 英文标签：Inter / Helvetica 一类无衬线

**固定元素（做成模板，每期复用）**
1. **滚动行情条**（底部）：指数、美债收益率、美元、黄金、比特币，左右滚动
2. **人名条（lower third）**：主播名 + 本期标题，左下角，琥珀色竖线
3. **数据卡**：大号等宽数字 + 涨跌箭头 + 来源小字
4. **引语卡**：讲话人照片的剪影/图标 + 原话 + 日期 + 来源（不要直接截新闻直播画面）
5. **标题卡/章节卡**："PART 1 发生了什么"，全屏 1.5 秒
6. **来源标注**：每张图右下角固定位置 `来源：FRED，截至 2026-09-30`

## 2. 画面素材的四个来源

| 类型 | 用途 | 去哪里找 / 怎么做 |
|---|---|---|
| **动态图表**（最重要） | 讲数据 | 用 [`tools/wallst_chart.py`](tools/wallst_chart.py) 直接从数据生成；复杂的用 After Effects / Remotion / Flourish |
| **B-roll 实拍** | 氛围、转场 | 素材库：Storyblocks、Artgrid、Pond5、Pexels/Pixabay（免费）——搜 trading floor、stock market、NYSE、Wall Street、Federal Reserve、container port、data center |
| **AI 生成 B-roll** | 素材库里找不到的画面 | 文生视频：交易大厅、曼哈顿航拍、发光的 K 线全息投影。提示词见 [`prompts/05-B-roll画面.md`](prompts/05-B-roll画面.md) |
| **屏幕录制** | 讲某只股票的走势 | TradingView 等平台按其使用条款注明来源；或用自己的数据重画 |

**不要用**：CNBC/彭博/福克斯商业的直播画面、别人视频里的片段——YouTube 版权识别会直接认领或下架。

## 3. 构图模板

```
┌─────────────────────────────┐   ┌─────────────────────────────┐
│                             │   │  ┌────────┐                 │
│         主播 全屏           │   │  │        │   动态图表       │
│      （钩子 / 结论）        │   │  │ 主播   │   + 数据卡       │
│ ▌Lena · 美联储又降息了      │   │  │ 左1/3  │                 │
│ SPX 5,xxx ▲ | US10Y 4.xx% ▼ │   │  └────────┘   来源：FRED    │
└─────────────────────────────┘   └─────────────────────────────┘
     A：全屏口播                       B：左人右图（最常用）

┌─────────────────────────────┐   ┌─────────────────────────────┐
│                             │   │                             │
│        全屏动态图表          │   │     B-roll 交易大厅          │
│                       ┌───┐ │   │     + 大字标题               │
│                       │主播│ │   │   "利率 = 钱的价格"          │
│  来源：BLS            └───┘ │   │                             │
└─────────────────────────────┘   └─────────────────────────────┘
     C：图表 + 右下小窗                D：B-roll + 大字
```

一期视频里 A:B:C:D 大约 **2:4:2:2**。

## 4. 剪辑节奏

- **画面每 3–5 秒一变**：可以是切镜、推近（主播 100% → 110%）、图表出新元素、换 B-roll。
- **信息每 15–20 秒一推进**：有新数字或新论点。
- **J-cut / L-cut**：下一段的声音先进（J），或上一段的声音延续到下一画面（L），转场更顺。
- **关键数字三连**：数字出现时 = 画面上大字 + 主播念出来 + 一个"叮/嗖"音效，三者对齐在同一帧。
- **字幕**：全程烧录中文字幕，关键词用琥珀色高亮；竖屏字幕放在画面中下 1/3，避开平台 UI。

## 5. 声音

| 轨道 | 响度 | 说明 |
|---|---|---|
| 人声 | 整体 -14 LUFS（YouTube 标准） | 加一点压缩和 EQ，让 AI 声音更"贴麦" |
| 背景音乐 | 比人声低 18–22 dB | 低沉、有律动的电子/Corporate 配乐，无人声；关键结论前停 1 秒 |
| 音效 | 适量 | whoosh（转场）、riser（钩子之前）、键盘/终端 tick（数据卡弹出）、低频 boom（暴跌数字） |

音乐用有授权的曲库（YouTube 音频库、Epidemic Sound、Artlist）。

## 6. 剪辑工程的轨道结构

```
V6  字幕
V5  行情条 / 人名条 / 来源标注（模板，锁定）
V4  数据卡 / 引语卡 / 大字
V3  主播（抠像后）
V2  图表 / B-roll
V1  虚拟演播室背景
A1  人声（TTS）
A2  音效
A3  背景音乐（ducking：人声出现时自动压低）
```

**工具**：剪映专业版（模板、智能抠像、自动字幕，上手最快）→ Premiere / 达芬奇（精修）→ After Effects / Remotion（复杂图表动画、程序化批量生成）。

## 7. 程序化图表：`tools/wallst_chart.py`

把 CSV（`date,value`）变成深色终端风的动态折线图 MP4：线条逐步画出、末端发光点、右上角数字计数器、涨跌自动变色、底部来源标注。

```bash
python3 tools/wallst_chart.py examples/sample_series.csv \
  --title "10 年期美债收益率" --unit "%" --source "示例数据，非真实行情" \
  --out out/chart_16x9.mp4                 # 横屏 1920×1080
python3 tools/wallst_chart.py examples/sample_series.csv \
  --title "10 年期美债收益率" --unit "%" --source "示例数据，非真实行情" \
  --out out/chart_9x16.mp4 --vertical      # 竖屏 1080×1920
```

数据从 FRED 等一手来源导出成 CSV 即可直接用。输出的是不透明背景的视频，直接放在 V2 轨道。

完整的分镜写法见 [`examples/分镜示例.md`](examples/分镜示例.md)。
