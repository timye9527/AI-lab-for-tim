## 0. 先回答：是网页，还是小红书里的东西？

**是网页。** 竞品的交付就是一个独立域名的 H5 网页：付款后店铺自动发一段「发货链接 + 发货说明（密码）」，买家复制到手机浏览器打开。
小红书小程序需要工信部备案和大陆主体，个人做不了，也不划算。我们和竞品一样走网页，这条路已验证可行（它卖了约 8.8 万单）。

## 2. 推荐的部署方式

| 方案 | 成本 | 大陆访问 | 结论 |
|---|---|---|---|
| **香港轻量服务器 + 自己的域名** | 服务器几十元 / 月 + 域名几十元 / 年 | 稳定，华南快 | **推荐**，步骤已写好：`docs/FRIEND-SOP.md` B 节 |
| Cloudflare Pages（`*.pages.dev`） | 免费 | 多地打不开 | 不用 |
| 大陆服务器 | 便宜 | 最好 | 要 ICP 备案，个人备案不能做经营性网站，不用 |

买服务器、买域名要花钱，**等主理人决定**，我没有自动购买。

## 3. 需要主理人做的（按顺序）

1. **确认店铺能卖虚拟商品（10 分钟）**
   - 在店铺后台新建商品时，看「虚拟商品 / 无需物流」和「自动发货」（发货链接 + 发货说明）能不能选。竞品就是这种发货卡片。
   - 拿不准类目就问商家客服，问法见 `docs/FRIEND-SOP.md` A 节，回复截图保存。
2. **买香港服务器和域名（20 分钟）**，按 `docs/FRIEND-SOP.md` B 节部署。部署完在服务器上建统一码：
   ```bash
   mm add 你自己定的码 jiucai      # 6～32 位字母数字，比如 JC 加四位数字
   ```
   用手机 4G 和 Wi-Fi 各打开一次 `https://你的域名/jiucai/`，再在小红书私信里复制网址到浏览器打开一次。
3. **上架商品（15 分钟）**：素材全在 `商品素材/`。
   - 标题、价格（0.99）、详情：复制 `上架文案.txt`。
   - 主图用 `01.png`，详情图按 `02`～`06` 顺序。
   - 发货：选自动发货，「发货链接」填你的网址，「发货说明」复制 `上架文案.txt` 里那段，把 `【统一码】` 换成第 2 步建的码。
   - 先**保存不提交**，自己看一遍预览；确认后再提交审核。
4. **自己下单买一次**，走完「收到发货卡片 → 复制网址 → 测完 → 输码 → 看完整报告」。
5. **笔记**：用手机或交给 Codex 存草稿。第一篇建议 `01-结果实拍`，挂上商品卡；之后每天 1 篇人物篇。发布由主理人点。

## 4. 账号怎么用

- 店铺所在的账号就是卖货出口。笔记、商品卡、段位卡上的品牌词统一是「韭菜段位测试」，这样买家晒图后别人能搜到。
- 如果店铺挂在原来做「表达 / 成长」的那个号上：可以先发 3～5 篇试水，看笔记 → 商品页点击率。点击率低就单独开一个「人格测试」定位的新号，避免和原账号的内容互相拖累。
- 账号定位写「人格测试 / 趣味心理」，**不要**写理财、炒股教学（财经内容 9 月起收紧，详见 `docs/LAUNCH-CN.md` 第 5 节）。

## 5. 上线后每天看什么

- 小红书后台：笔记 → 商品页点击率、商品页 → 下单转化率。
- 服务器：`mm stats` 看「打开 → 开测 → 测完 → 存卡 → 解锁」漏斗。
- 判断方法见 `docs/GAME-DESIGN.md` 第 7 节；每周把两边数据截图发给 Claude 做复盘。
