# 竞品拆解 · 「前世人物志｜你像哪位历史人物」（0.99 元，约 8.8 万单）

> 依据：主理人 2026-10-10 花 0.99 元实测的 5 张截图（下单后的自动发货消息、答题页 3 张、结果长图 1 张）。
> 本环境网络访问不了对方网页，也看不到它的引流笔记。凡标「推测」的，需要在小红书里搜一下验证。
> 销量数字来自主理人看到的商品页；之前（`GAME-DESIGN.md` 写作时）是 7.7 万单，说明还在持续出单。

## 1. 它到底卖的是什么

| 环节 | 看到的事实 | 背后的设计 |
|---|---|---|
| 商品 | 「趣味测试了解自己的…」，0.99 元，个人店（店名是一个普通昵称 + 「的店」） | 价格低于「要不要想一想」的门槛；个人店就能卖 |
| 付款后 | 店铺客服（带「ai」标）自动发一张「商品已发货」卡片：**发货链接** + **发货说明**（一个统一密码、复制到浏览器、不限次数和时间、有问题找客服） | 全自动交付，零人工。**所有买家用同一个密码**，不用管理卡密库存 |
| 交付形态 | 独立域名下的 H5 网页，不是小红书小程序 | 小程序要备案和大陆主体，网页最省事；域名下还有别的测试，是一个**测试矩阵**（推测） |
| 答题 | 24 题，按章节分组（人际协作、判断与洞察、行动与变化……），顶部有章节名 + 「1/24 4%」进度条；选完自动下一题 | 题多 = 「测得准、值这个价」的感觉；章节和百分比降低半途放弃 |
| 题目 | 「古代大型水利工程即将交给新人接手…」「明代海防同时出现倭患与粮饷短缺…」「古代粮仓账册亏空…」 | **角色扮演**：你在古代当官做决定。和「前世」主题一致，比普通性格题好玩 |
| 选项 | 每个选项下面直接写「更接近『表达 / 经营 / 独立 / 担当』的行为倾向」 | 公开维度，让人觉得「我在选我想成为的人」，结果自然「准」 |
| 结果 | 92% 匹配 · 诸葛亮 · 「三国 · 长期主义谋臣 · 谋略家」· 3 个标签 · 主导维度 · 人物心声 | 大号百分比 + 体面人物 = 想截图 |
| 报告 | 01 人物自画像 → 02 八维能力条 → 03 共同底色（三张小卡）→ 04 现实中的你 → 05 盲点与风险提醒 → 06 三句人物台词 | 6 段、一屏一段，长截图刚好能发 |
| 售后 | 发货消息末尾：「星 + 10 字带图好评，送其他工具」 | 刷好评、刷晒图、顺便把买家导到别的产品（**这一条我们不学，见第 4 节**） |

## 2. 为什么能卖到 8 万多单

1. **被夸的快乐。** 结果几乎都是体面的人物（诸葛亮、谋略家、长期主义），再加一个 92% 的精确数字。人愿意为「被一个权威框架认可」付 1 块钱，更愿意把它晒出去。
2. **决策成本几乎为零。** 0.99 元 + 夜里刷到（实测订单在凌晨）+ 一键下单。没人会为 1 块钱比价。
3. **「我到底像谁」的好奇缺口。** 标题本身就是一个问题，答案只有付了钱才知道。
4. **结果天然是社交货币。** 「我是诸葛亮」比「我是 INTJ」更好聊，评论区可以对人物、互相 @ 朋友去测。
5. **看起来很专业。** 24 题、八维、主导维度、能力条，让人觉得这 1 块钱「花得值」，退款和差评就少。
6. **交付无摩擦。** 统一密码、不限次数，买家还能转给朋友用。表面上是漏洞，实际上朋友测完也会晒，等于免费传播。
7. **规模化成本是零。** 内容一次写完，交付全自动，每多一单都是纯利润（除去平台扣点）。

一句话：**低价冲动消费 × 被夸的身份认同 × 能晒的结果 × 全自动交付。**

## 3. 它的短板（我们的机会）

- **报告模板化。** 三张「共同底色」卡用的是同一句套话（「这也是你与诸葛亮最接近的一层性格底色」），细看比较空。
- **没有分享卡。** 结果是一个长网页，用户只能自己截长图（推测：看到的是网页长截图）。
- **没有免费层。** 不付钱什么都看不到，传播全靠买家自发截图。
- **题目和钱、和真实生活离得远。** 「明代海防」很好玩，但测完和自己的生活没关系。

## 4. 我们照着学什么、不学什么

**学：**

| 竞品做法 | 我们（韭菜段位测试）怎么落 |
|---|---|
| 0.99 元、个人店、全自动发货 | 同样 0.99 元；店铺用「虚拟商品自动发货」，发货内容 = 网址 + 统一兑换码 |
| 统一密码，零卡密运维 | 引擎支持「统一兑换码」（`admin add`），码泄露了随时换一个；也保留一人一码模式 |
| 章节 + 进度百分比 | 答题页加章节名和进度百分比 |
| 题量撑起「专业感」 | 12 题扩到 16 题，约 3 分钟 |
| 体面人物 + 大号匹配度 | 已有：16 位历史人物、匹配度、主导维度、人物心声 |
| 6 段式报告 | 已有 7 段：四维图谱、自画像、财商六维、共同底色、真实故事（有出处）、盲点与提醒、搭子与天敌 |

**我们比它多的：**

- **免费段位卡**（自嘲梗：韭菜盒子、渡劫失败老韭菜），一键生成竖版海报，卡上写「小红书搜『韭菜段位测试』」。
- **真实故事有出处**，人物心声明确是编写的，不怕被挑错。
- **搭子与天敌**，自带拉朋友来测的理由。
- **题目贴近每个人的钱包**（追涨、抄底、小道消息、年终奖），测完有话聊。

**不学：**

- **「带图好评送东西」**：小红书电商规则禁止以利益诱导好评，轻则商品降权，重则店铺处罚。不做。
- **把买家导到站外其他产品**：交易导流规则最重永久封号。网址只出现在付款后的发货内容里，网页上不引导加微信、不卖别的东西。
- **照搬它的文案和题目**：玩法可以借鉴，具体文字、题目、版式都用我们自己的。

## 5. 笔记怎么推（推测 + 我们的打法）

对方的引流笔记没看到，下面是按这类产品的常见打法推的，**明早可以在小红书搜「你像哪位历史人物」看前 10 篇验证**：

1. **晒结果型**：「测出来我是诸葛亮，92%……有点准」，配结果长截图。看起来像普通用户的分享。
2. **合集型**：「16 种结果你是哪个」，一张图一个人物，评论区自然有人问「在哪测」。
3. **题目型**：放一道好玩的题，「你选哪个」，评论区互动拉权重。

我们的打法见 `docs/PLAYBOOK.md` 和 `docs/LAUNCH-XHS.md`；所有笔记都挂店铺商品卡，正文和图片里不出现网址、二维码、微信。

## 6. 用户心理画像（买 0.99 元测试的人）

- 18～30 岁，晚上刷小红书，喜欢 MBTI、星座以外的「新人格测试」。
- 买的不是信息，是**一个关于自己的好故事**和**一张能发出去的图**。
- 在意「准不准」，其实在意的是「被说中」：描述要具体到行为（「上厕所也要看一眼分时图」），不要空泛的形容词。
- 财经方向的额外动机：**自嘲**（被割过的人很多）、**对暗号**（「你是冲独快断吗」）、**想知道自己适不适合炒股**（只能讲习惯，不能给投资建议）。
