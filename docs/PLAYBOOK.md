# 运营打法 · 从一篇笔记到一笔订单

> 平台规则（类目、虚拟商品资质、卡密发货方式、违禁词）经常变。下面凡是涉及平台规则的地方，**上架前都要在商家后台和社区规范里再核实一遍**。
> 开店主体、类目、部署和财经内容红线的调研结论见 [`LAUNCH-CN.md`](LAUNCH-CN.md)。

## 1. 闭环

```
笔记（钩子）→ 商品卡（0.99 元兑换码）→ 测试页 → 段位卡（免费）→ 用户晒图发笔记 → 新的人看到 → …
                                         └→ 完整报告（兑换码解锁）
```

- **商品卡是合规出口。** 笔记里别放外链和二维码，用商品卡和「小红书搜 XX」来导流。
- **段位卡免费，报告收费。** 免费的部分负责传播，付费的部分负责「我想知道更多关于我自己的事」。
  如果发现免费卡太够用、没人付费，把 `paywall.mode` 改成 `'start'`，就变成先付费再测。

## 2. 为什么有人愿意晒

| 设计 | 作用 |
|---|---|
| 段位名带梗（韭菜盒子、渡劫失败老韭菜） | 自嘲是社交货币，适合发群 |
| 人格是人人都熟的历史人物（曹操、诸葛亮、司马懿、李白、刘禅……） | 一看就懂、有体面，晒得出去，评论区还能接梗 |
| MBTI 式的四维代码 + 主导维度 + 共同底色 | 满足「我到底是什么样的人」的自我探索需求，这才是付费的理由 |
| 匹配度百分比、四字代码（冲独快断） | 精确数字让人觉得准，代码方便在评论区对暗号 |
| 自己起花名上卡 | 有参与感，每张卡都不一样 |
| 搭子 / 天敌 | 自带拉朋友来测的理由 |

## 3. 定价

- **0.99 元**：降低决策门槛，靠量和销量数字做信任。
- 后续可以加的高客单（还没做）：
  - **双人财务契合度**（情侣 / 室友 / 合伙人），9.9 元，两个人都得测，自带裂变；
  - **年度复盘版**：同一套题测两次，对比段位变化。
- 长期价值：把测过的人引到你自己的财经账号上。

## 4. 笔记怎么发

**图片结构（参考 8 张）**

1. 封面：一句扎心的大字（如「有些人炒股，迟早会变成韭菜盒子」）
2. 段位天梯：6 个段位名 + 图标
3～6. 4 张人格卡预览（人物 + 心声金句）
7. 一道题截图，让人在评论区说「我选 A」
8. 引导：「测试入口在下方 👇」

**标题公式**

- 「测出 ___ 的人，都有一个毛病」
- 「原来我炒股的样子，跟 ___ 一模一样」
- 「你的炒股人格，是三国里的谁？」

**选题池（可以发很多篇）**

- 16 位人物，一篇一个：「测出司马懿型的人，都特别能熬」「测出刘禅型的人，账户一年没打开过」
- 6 个段位，一篇一个：「韭菜盒子是怎么炼成的」
- 搭子 / 天敌：「曹操型和刘禅型，天生互相看不惯」「刘邦型的最佳搭子，果然是张良型」
- 借势：年终奖到账、春节红包、开门红、财报季、双十一、大涨或大跌那天。题目和文案都不用改，换封面就行

**话题标签**：测试类 + 财经类 + 人格类混搭，具体用哪些看当下的热度。

## 5. 冷启动两周

| 时间 | 做什么 |
|---|---|
| 第 1 周 | 部署、导入兑换码、上架商品；自己和朋友测一遍，收集「准 / 不准」的反馈，改文案 |
| 第 2 周 | 发 10～15 篇笔记（人物篇为主，加 2～3 篇借势篇） |

**只看三个数**

1. 笔记 → 商品页的点击率
2. 商品页 → 下单的转化率
3. 有没有人**自发**晒段位卡

**怎么判断下一步**

- 有人自发晒 → 加码发笔记，开始做第二套测试
- 有人买、没人晒 → 结果页不够好晒，改段位卡和金句
- 没人点商品 → 钩子不行，改封面和标题
- 点了不买 → 商品页说服力不够，放结果截图、写清楚报告里有什么

## 6. 合规清单（财经领域格外重要）

- 不推荐任何具体股票、基金或板块；不承诺收益。
- 不叫「投资能力评估」「风险测评」。那是持牌机构做适当性管理用的，这里只是**娱乐 / 性格测试**。
- 商品标题和笔记里别用「财运」「转运」「算命」这类词。
- 商品描述写清「娱乐测试，虚拟商品，兑换后不支持退款」，减少售后纠纷。
- 每个人物的真实故事都写了出处（`fact` 字段）；「人物心声」是编写的金句，不冒充原话（李白那句本来就是他的诗）。

## 7. 复用：下一套测什么

同一个引擎，换一份 `config.js`：

- **粤语段位**：港剧观众 → 茶餐厅熟客 → 地道师奶，配合你的粤语学习网站引流
- **打工人搞钱段位**：副业、存钱、消费习惯
- **节气 / 节日限定**：只换封面和少量文案，单独上架一个商品
