# 财经浩谈 · 爆款打法与数据迭代手册

> 写于 2026 年 10 月。前半部分是调研结论（YouTube 官方机制、头部团队的公开方法、中文知识区头部 UP 主），后半部分是落到流水线上的改动和数据迭代方法。
> 调研来源多为二手整理，凡是第三方经验值都标了「参考」，**最终以自己频道后台数据为准**。

## 一句话

**先包装，再内容；开头兑现点击，中段用因果推着走，结尾兑现悬念；每一集都是一次实验，用后台数据决定下一集怎么改。**

v1（复刻现有节目）和 v2（按本手册重做）用的是同一份事实，可以直接对比：`out/video/demo/` 和 `out/video/demo-v2/`。

## 1. 平台怎么判断一条视频好不好

| 机制 | 事实 | 对我们的意思 |
|---|---|---|
| 推荐看「观众满不满意」，不只看点击 | YouTube 的 A/B 测试工具「测试与比较」用**观看时间份额**选赢家，不是点击率（[来源](https://thumbnailtest.com/news/youtube-releases-title-test-compare/)）：点击高但马上走的封面会输 | 标题封面要「吸引人 + 不骗人」，开头必须兑现封面 |
| 开头 30 秒有专门指标 | Studio 的「开头」（Intro）指标显示 30 秒时还剩多少人；第三方经验值 60～70% 算好（[来源](https://influencernotes.com/academy/whats-a-good-retention-rate)、[来源](https://artiphik.com/blog/the-first-10-seconds-retention-playbook)） | 开头 30 秒是全片最值得花工夫的地方 |
| 观看百分比按时长看 | 参考：5 分钟以下 60%+ 算强，15 分钟以上 30～40% 算强（[来源](https://www.teleprompter.com/blog/youtube-audience-retention)） | 不要拿不同长度的片比百分比 |
| 观众分新 / 偶尔 / 常客 | 2025 年 7 月起 Studio 把观众分成新观众、偶尔观众、常客三类（[来源](https://ppc.land/youtube-introduces-refined-viewer-analytics-with-casual-and-regular-metrics/)） | 常客数是节目 IP 有没有立起来的指标 |
| Shorts 先看「有没有划走」 | 「已观看 vs 划走」是 Shorts 的第一道筛选，第三方建议 70%+（[来源](https://subscribr.ai/youtube-strategy/youtube-shorts-analytics-metrics-growth)） | Shorts 第一句就要有钩子，第一帧就要有字 |
| AI 内容会被区别对待 | 2025 年 7 月 YPP 把「大量重复内容」改称「不真实内容」，强调加入原创评论、剪辑、讲解的 AI 内容仍可变现（[来源](https://alternativeto.net/news/2025/7/youtube-updates-its-policy-to-demonetize-inauthentic-mass-produced-ai-generated-content)）；CEO 2026 年公开信把减少「AI 垃圾内容」列为重点（[来源](https://au.variety.com/2026/digital/global/youtube-channels-using-ai-tools-reduce-slop-neal-mohan-letter-32190/)）；逼真的合成内容要申报，明显是动画的不用（[来源](https://www.websiteplanet.com/news/youtube-ai-disclosure)） | **AI 只做生产，观点必须看得出是人的**：署名、原创判断、固定人设。卡通形象属于明显的动画，但用 AI 声音冒充真人时要申报 |

## 2. 头部团队的方法

| 来源 | 方法 | 我们怎么用 |
|---|---|---|
| Paddy Galloway（YouTube 策略顾问） | 包装先于制作；标题和封面一起算「包装」，包装不清楚的点子直接放弃；「一眼测试」：封面一瞥就要看懂；每条视频做 3 张封面、10 个标题（[来源](https://www.colinandsamir.com/resources/the-new-rules-of-youtube-from-paddy-galloway)、[来源](https://podcast.creatorscience.com/paddy-galloway/)） | 改稿规则第一条就是「先包装」；每集 3 个标题 + 3 张封面 |
| MrBeast 制作手册 | 第一分钟决定大部分人留不留；之后要快速推进；约 3 分钟、6 分钟各放一个「再勾一次」的段落；后半段靠兑现（[来源](https://www.danielscrivner.com/how-to-succeed-in-mrbeast-production-summary/)、[来源](https://cybernews.com/news/mrbeast-leaked-pdf-spills-secrets-how-to-be-successful-on-youtube/)） | 每章开头用一个新问题重新勾住；开场埋的悬念在最后一章兑现 |
| South Park 编剧的「但是 / 所以」规则 | 情节之间用「但是」或「所以」连接，不用「然后」（[来源](https://perell.com/note/but-therefore-rule/)） | 章节标题写成问题，章与章之间用「但係 / 所以」接 |
| Kurzgesagt | 配音定节奏，动画跟配音走；脚本找专家核对（[来源](https://kurzgesagt.org/youtube/)） | 流水线本来就是「配音定时长」；数据标出处、发布前核对 |
| 小Lin说（B 站头部财经） | 「说人话」、用生活比喻讲专业概念；选题贴近民生；据观众观察，几十秒就插一次特效；42 分钟的年度总结在 B 站播放超过 435 万（[来源](https://www.sohu.com/a/858533012_121124293)、[来源](https://index.datastory.com.cn/article/121)、[来源](https://www.zhihu.com/question/537496812)） | 每期都要回答「跟你的钱有什么关系」；画面持续有变化 |
| 所长林超 | 「划重点」大字幕；固定人设（「不眨眼的林超」）让人记住；讲十四五规划的视频全网播放超过 1.7 亿（[来源](https://static.nfapp.southcn.com/content/202007/29/c3830940.html)、[来源](https://baike.baidu.com/item/%E6%89%80%E9%95%BF%E6%9E%97%E8%B6%85/53218487)） | 字幕里的数字和重点词自动高亮；主持人要有名字和口头禅 |
| B 站知识区 | 封面文字不超过 8 个字、元素不超过 3 个；标题「痛点 / 疑问 + 亮点」（[来源](https://www.huasheng.ai/insights/bilibili-video-best-practices/)） | 封面每行不超过 5 个字，两行 + 一个数字 |

**香港本地的信号：** YouTube 香港 2025 年度十大热门创作者里，理财频道「我要做富翁」排第三，是排名最高的本地频道；按其中一种统计，十大里有六个是知识 / 资讯型频道（[来源](https://www.am730.com.hk/article/1007538)、[来源](https://inews.hket.com/article/4077045)）。「我要做富翁」走的是实用教学 + 多位导师 + 课程转化（[来源](https://edu.money-tab.com/)）。**香港观众愿意看财经，前提是「跟我有关、听得懂」。**

## 3. v2 改了什么，为什么

| 改动 | 依据 | 在哪里改 |
|---|---|---|
| 去掉标题卡和「欢迎收看」，第一帧就是封面 A 的插画 + 数字 | 开头 30 秒指标；测试工具按观看时间选封面，开头不兑现封面会输 | 分镜：第一个场景用 `sketch` |
| 第二个场景讲「跟你有什么关系」（强积金 / 基金） | 小Lin说的选题方法；香港观众偏好实用 | 改稿规则第 3 条 |
| 开场埋悬念（「片尾 3 个讯号」），最后一章兑现 | 好奇心缺口 / 开放式悬念 | 改稿规则第 3、8 条 |
| 章节写成问题，用「但係 / 所以」连接 | 「但是 / 所以」规则；MrBeast 的再勾一次 | 改稿规则第 4 条 |
| 右上角章节进度「02/04」 | 让观众知道还剩多少，降低中途离开 | 引擎：`chapter.total` |
| 画面一直有轻微推近，元素出现时配「啵」音效，换场景「嗖」一声 | 头部团队几十秒一个特效；静止画面是流失点 | 引擎：`motion`、`sfx`（默认开） |
| 字幕里的数字和重点词自动高亮 | 所长林超的「划重点」大字幕 | 引擎：字幕自动高亮 `*星号*` 词和数字 |
| 结尾「A 还是 B？」+ 预告下集回应留言 | 评论是满意度信号；给观众回来的理由（常客） | 改稿规则第 8 条 |
| 3 个标题 + 3 张封面（插画 + 数字 / 主持人表情 / 纯大字） | Galloway：多做几版；YouTube 测试与比较最多测 3 个 | `titles`、`thumbs` |
| 署名栏 | AI 内容政策：观点要看得出是人的 | `byline` |

v1 和 v2 的拆解对比见第 6 节。

## 4. 怎么调：参数和对应的数据

| 后台看到的问题 | 先调什么 | 流水线里的开关 |
|---|---|---|
| 曝光点击率低于频道中位数两成 | 封面：换类型（插画 / 表情 / 大字）；标题：换角度（数字 / 冲突 / 悬念） | `thumbs`、`titles`，用「测试与比较」 |
| 点击高，但 30 秒留存低 | 封面和开头不对版：第一句兑现封面上的那个数字或问题 | 第一个场景的 `say`、`labels` |
| 30 秒还好，1～3 分钟掉得快 | 背景铺垫太长：把「跟你有关」和悬念提前；删掉第一章里不影响结论的细节 | 前两个场景；第一章场景数 |
| 某个场景掉得特别快 | 看 `video:review -- retention` 的「掉人最快的 3 个场景」：太长就拆，信息重复就删 | 拆场景；`beats` 让元素出得更早 |
| 某类场景普遍掉人 | `video:review -- scenes` 的场景类型表：差的类型限制长度或少用 | 改稿规则第 5、7 条 |
| 结尾前大量离开 | 悬念兑现太晚或太弱；结尾太长 | 兑现场景前移；`outro` 控制在 8 秒内 |
| Shorts 划走率高 | 第一句不够狠；第一帧没字 | `short` 段的第一个场景 |
| 观看时间份额赢的封面类型连续 3 集一样 | 把它定为默认，下一轮测别的变量 | `thumbs` 顺序 |

节奏相关的默认值（都在 `video/README.md` 有说明）：数据卡 12 秒、逐个出现的场景 20 秒会提醒拆分；镜头推近幅度 3.5%；音效音量 `sfxVolume`；配音语速 `rate`。

## 5. 数据迭代：每一集都是一次实验

### 北极星指标

**每次曝光带来的观看时间 ≈ 点击率 × 平均观看时长。** 它同时反映包装和内容：只骗点击，平均观看会掉；内容好但没人点，点击率会掉。频道增长再看**常客数**（IP 有没有立起来）。

### 流程（每周一次）

1. 片子出街满 7 天后（大部分观看发生在第一周），从 Studio 导出「内容」表格，跑 `npm run video:review -- channel 表格.csv`。
2. 对判断为「留存低」的那集，把留存曲线存成 `video/episodes/<集id>/stats/retention.csv`，跑 `npm run video:review -- retention <集id>`，定位到场景。
3. 累积 5 集以上后跑 `npm run video:review -- scenes`，看哪种场景类型最掉人，回头改 `video/prompts/draft.md`。
4. 在 `video/experiments.md` 记一行：这集改了什么、结果如何、下一步。

### 实验规则

- **一次只改一个大变量**（开头、节奏、长度、选题角度），封面标题用「测试与比较」在同一集里测，不占这个名额。
- **每个做法至少跑 3 集**再下结论，单集波动太大；对比基准是**最近 10 集的中位数**，不是某一集。
- 只比「出街后 7 天」的数据，避免新旧片累积时间不同。
- 结果写进 `video/experiments.md`，赢的做法写回改稿规则，成为新的默认。

### 第一批实验

| # | 假设 | 做法 | 看什么 | 怎样算赢 |
|---|---|---|---|---|
| E1 | 插画 + 大数字的封面比纯大字好 | 每集 3 张封面跑「测试与比较」 | 观看时间份额 | 同一类型连续 3 集胜出 → 定为默认 |
| E2 | 冷开场（数字 + 跟你有关 + 悬念）比标题卡开场留得住 | 连续 3 集用 v2 开场 | 30 秒留存（Intro） | 比最近 10 集中位数高 10 个百分点 |
| E3 | 画面持续动 + 音效 + 字幕高亮能减少中段流失 | 连续 3 集开 `motion`、`sfx` | 平均观看百分比；1～3 分钟的曲线斜率 | 平均观看百分比高于中位数 |
| E4 | 6～8 分钟比 10～12 分钟更适合现阶段 | 同类选题做两种长度 | 每次曝光带来的观看时间 | 高的那个；超过 8 分钟可以加中插广告，有变现时一起算 |
| E5 | 每集 2 条 Shorts 能给长视频带人 | 每集出 2 条 Shorts，置顶评论 / 关联视频指向长片 | Shorts「已观看 vs 划走」；长片流量来源里 Shorts 的占比 | 划走率低于 30%；长片新观众增加 |
| E6 | 「跟香港人钱包挂钩」的角度点击更高 | 同周两集：纯宏观 vs 挂钩强积金 / 楼按 / 港股 | 点击率、平均观看 | 点击率高 20%+ |
| E7 | 亮出分析师身份能提升信任（需本人和公司同意） | 片头署名 + 简介 | 订阅转化、常客数 | 订阅 / 千次观看提升 |

## 6. v1 vs v2：同一份事实，两种做法

两版都是无声版（云端没有配音），时长按字数估算，所以只比结构和画面。数字由渲染脚本和 `video:teardown` 测出。

| 项目 | v1（复刻现有节目） | v2（按本手册） | 依据 |
|---|---|---|---|
| 时长 | 3:12 | 2:42 | 删掉标题卡和重复铺垫 |
| 第一帧 | 纯文字大字卡，和封面插画不是同一个画面 | 封面 A 的同一张插画 + 同一个数字 | 开头兑现封面 |
| 标题卡 / 「欢迎收看」 | 有（0:12） | 无 | 开头 30 秒 |
| 「跟你有什么关系」 | 无 | 0:08（强积金 / 基金） | 实用、贴近生活 |
| 开放式悬念 | 无 | 0:14 埋下，2:10 兑现 | 好奇心缺口 |
| 章节是问题句 | 0 / 4 | 4 / 4，用「但係 / 所以」连接 | 因果推进 |
| 画面新元素（不含字幕） | 旧模板 81 次，平均 2.4 秒一次（新模板 95 次 / 2.0 秒） | 91 次，平均 1.8 秒一次 | 持续有新东西 |
| 最长空档（没有新元素） | 10.9 秒；超过 6 秒的，旧模板 10 处、新模板 6 处 | **6.0 秒，0 处** | 静止画面是流失点 |
| 镜头微推 / 入场音效 | 关（对照组） | 开 | 头部团队的剪辑密度 |
| 字幕重点高亮 | 有（引擎升级后两版都有） | 有 | 「划重点」字幕 |
| 结尾互动 | 「你点睇？」 | 「A 泡沫 / B 新时代」二选一 + 预告下集回应 | 评论、常客 |
| 标题 / 封面 | 1 / 1 | 3 / 3，可直接上「测试与比较」 | 包装实验 |
| 打法检查提醒 | 6 条（钩子超过 45 字、有标题卡、章节不是问题、少于 3 个标题、少于 3 张封面、无署名） | 0 条 | — |

过程本身也是一次迭代：v2 第一版的最长空档还有 10.4 秒，问题出在模板（金句一次过出现、数字卡注释出完就没下文、对比栏整块出现、结尾一秒后就静止）。改了模板之后，**v1 用同一份稿也从 10 处空档降到 6 处**；再把 v2 的 12 秒开场拆成两段，空档降到 0。

**还不能说明的事**：这些只是「做对了动作」，播放量要上线后看后台数据。所以第 5 节的实验才是关键。

## 7. 其他平台

- **YouTube 为主**：粤语观众、香港本地、可变现，「测试与比较」能做包装实验。
- **Facebook / Instagram Reels**：香港用户多，Shorts 素材可以直接复用（同为 9:16）。
- **B 站、视频号等内地平台**：观众以普通话为主；券商品牌的财经内容跨境推广涉及监管问题，**上之前必须问公司合规**，本手册不建议直接铺。
