# 视频制作新手指南 · 给主理人

> 从做过的 7 个视频项目里总结出来的：一条视频是怎么做出来的、你在哪几步拍板、怎么下单最省事、什么费 token / 流量 / 时间 / 显卡 / 钱。
> 给 AI 助手看的执行版是 `.claude/skills/video-qa/`（质检流程、错误档案、选型速查），做视频时它会自动用。

## 一、一条视频是怎么做出来的

```
需求卡 → 稿件 → 读音表 → 声音样片 → 全量配音 → 关键帧 → 渲染 → 成片体检 → 交付
  你定      你过稿     自动        你点头       自动       自动     自动      自动      你验收
```

| 步骤 | 大白话 | 为什么不能跳 |
|---|---|---|
| 需求卡 | 平台、时长、什么声音、什么画风、什么时候要 | 声音和画风没说清，做完全片才发现不对，是以前最大的返工来源 |
| 稿件 | 口播稿 + 出处 + 画面安排；先跑一遍自动预检 | 「总得」「一层一层」「2025」这类以前读错过的写法，在这一步改掉最便宜 |
| 读音表 | 每句话逐字标出拼音，多音字一个个确认 | 语音识别听不出声调，「得」读成 dé 还是 děi 它分不出来，只能靠这张表 |
| 声音样片 | 先做 30～60 秒，挑全片最难读的一段 | 你听一下音色、语速、情绪对不对。改样片几分钟，改全片几十分钟到几小时 |
| 全量配音 | 逐句合成，每句用语音识别回听；不对就重读，8 次不过就改写句子 | 模型偶尔会重复音节、吞字 |
| 关键帧 | 不渲染视频，先出一张 9 格拼图看版面 | 孤字、文字越界在这里改，不用等渲染 |
| 渲染 | 一帧一帧画出来、合成 mp4 | 最费时间的一步，所以放在最后 |
| 成片体检 | 自动查规格、响度、黑屏、静音、画面长时间不动、字幕 | 手机放不了、声音忽大忽小、首帧黑屏这类问题 |
| 交付 | 成片 + 质检结果 + 发布包 | 你只需要看结论和「需要你做的事」 |

## 二、你只需要拍板三次

1. **需求卡**：开工时一次答完（下面有模板）。
2. **声音样片**：听 30～60 秒，确认音色、语速、风格。**点头之后这些就不再改**，要改就是回到这一步重来。
3. **验收成片**。

其他环节 AI 自己过关，过不了才会来问你。

## 三、下单模板（复制、填空、发给 Claude）

```
做一条视频。
平台和画幅：抖音竖屏 / YouTube 横屏 / ……
时长：约 X 分钟
主题和素材：（链接、原稿、要讲的观点）
声音：AI 男声沉稳解说 / AI 女声 / 我本人声音 / 我自己录；参考：（某个视频或「像 XX 那样」）
画面：金句大字卡 / 数据图表 / 火柴人动画 / 地图 / ……；参考哪一期
配乐：要 / 不要；情绪
截止：X 月 X 日；预算：0 元（只用本机）/ 可以花 XX 元
其他：不能出现的东西、必须有的东西
先给我声音样片再做全片。
```

最后一句可以不写，质检流程默认就会先出样片。

想要更快：说「照 XX 那期做」，AI 会直接复用那期的管线、声音和版式。

## 四、钱、时间、token、流量、显卡：什么费什么

### 1. Token（AI 的「阅读量」，直接决定用量额度）

AI 每读一个文件、每看一张图、每看一屏日志，都算 token。对话越长，后面每一轮都更贵。

| 费 token 的事 | 大致量级 | 怎么省 |
|---|---|---|
| **返工**：全片做完再改声音、改风格 | 一次返工 ≈ 重新做一遍大半流程 | 需求卡一次说清；先出样片 |
| 看图 | 一张截图约 1～1.5 千 token | 9 帧拼成一张图看，省 8 成；只在样片、关键帧、成片三个时点看 |
| 读大文件 | 800 行的画面代码约 1 万 token | AI 先搜索定位再看局部 |
| 渲染 / 合成日志 | 不压日志能刷几千行 | 只看报错和最后几行 |
| 每次贴全文稿 | 一期稿子 2000 字左右 | 只看改动的句子 |
| 反馈分很多轮给 | 每轮都要重新理解上下文 | 看完样片把意见一次给全 |
| 开新会话重新讲背景 | 每次都要重读文档 | 在同一个会话里接着做同一期；跨会话靠仓库里的文档和错误档案接力 |

### 2. 流量和下载（不占 token，占时间）

| 东西 | 大小 | 说明 |
|---|---|---|
| 内容工厂的配音 + 回听模型 + 字体 | 约 1.6 GB | 第一次跑要下载 |
| ZipVoice 克隆模型 | 约 800 MB | 存储视频、微电影用 |
| 蕲春的地图数据 | 约 340 MB | 下载约 2 分钟 |
| 成片 | 1080p 每分钟大约十几到几十 MB | 发到手机看要等传输 |

**注意**：云端会话的电脑是临时的，**换一个新会话，下载过的模型就没了**，要重新下。常做视频的话，可以把下载步骤写进云端环境的初始化脚本（setup script），开会话时自动装好。成片和模型不要提交进仓库（会让仓库越来越大）。

### 3. 时间（机器在跑，你在等）

这台云端电脑：4 核 CPU、15 GB 内存、没有显卡。实测：

| 环节 | 实测用时 |
|---|---|
| 稿件预检、读音表 | 几秒 |
| 关键帧拼图 | 几秒到一分钟 |
| 内容工厂 8～9 分钟竖屏，整片渲染 | 约 4 分钟（没变化的帧直接复用） |
| 存储视频 6 分 47 秒 1080p，整片渲染 | 约 20～30 分钟 |
| 微电影 94.5 秒，画面渲染 | 约 2.5 分钟 |
| 粤语 3 分钟示范片 | 预览约 1～2 分钟，正式约 4 分钟 |
| 蕲春 156 秒 3D 地形片 | **一个画幅约 1～1.5 小时**（没显卡，软件渲染） |
| 成片体检 | 每分钟片长约 10 秒 |
| 配音 | 逐句缓存，改一句只重配这一句 |

省时间的做法：只重配改过的句子、只重渲改过的段落；4 核机器上不要同时开多个渲染（实测更慢）。

### 4. 显卡（GPU）

我们的流程**刻意不用显卡**，所以在云端能跑。下面这些需要显卡，这里做不了：

| 需要显卡的事 | 替代办法 |
|---|---|
| AI 视频生成（可灵、即梦这类） | 你在它们的网站上用自己的账号生成，素材交回来剪 |
| 高质量对口型（MuseTalk、LatentSync） | 两张图张嘴 / 闭嘴切换；或用 HeyGen 这类付费服务 |
| 3D 电影级渲染（Blender） | 程序化 2D 动画 |
| 训练自己的声音模型 | 零样本克隆（ZipVoice，只要一段录音，CPU 能跑） |

### 5. 钱

到目前为止 7 个项目**都是 0 元**：开源模型、开源字体、代码合成配乐。可能花钱的地方：

| 选项 | 大概花费 | 什么时候值得 |
|---|---|---|
| 真人录音 | 0 元（找朋友录） | 最推荐，效果最好 |
| 剪映 / 火山引擎 / 谷歌云配音 | 几元到几十元一条 | 想要更自然的男声解说 |
| 可灵、即梦 AI 视频 | 60 秒片约 200～500 元 | 一定要 3D 电影质感时；价格以官网为准 |
| 授权配乐 | 看曲库 | 想要比代码合成更有质感的音乐 |

## 五、以前为什么老返工

| 发生了什么 | 哪一期 | 现在怎么防 |
|---|---|---|
| 第一版男声「怪」，换模型重配全片 | 内容工厂 001 | 样片先定声音 |
| 配音「有口音、有点呆」 | 微电影 | 同上，候选音色先筛 |
| 「读法不自然、重音不对」 | 蕲春 v2 | 同上 |
| 声音换了 4 轮 | 存储视频 | 需求卡第一项问声音 |
| 「总得」5 处读错已经交付 | 内容工厂 001 | 预检直接报；只认实际声音 |
| 配乐有电波杂音 | 存储视频 | 混音前单独听配乐 |

完整清单在 `.claude/skills/video-qa/错误档案.md`，每次新踩的坑都会加进去，并变成自动检查。

## 六、术语小词典

| 词 | 意思 |
|---|---|
| TTS / 配音模型 | 文字转语音 |
| ASR / 回听 | 语音转文字，用来检查配音有没有读错、漏字 |
| 多音字 | 一个字几种读法（得、长、行、调……），配音最容易错的地方 |
| 变调 | 「一」「不」和两个三声字连读时声调会变（一样读 yí，你好读 ní hǎo） |
| 轻声 | 的、了、着这类读得又轻又短的字 |
| 9:16 / 16:9 | 竖屏 / 横屏 |
| 帧率 | 每秒多少张画面，常用 25 或 30 |
| 渲染 | 把画面一帧一帧画出来再合成视频 |
| LUFS（响度） | 声音整体有多响。平台大多按 -14 统一，太小声或太大声都会被调 |
| 采样率 | 声音的精细程度，16 kHz 偏闷，48 kHz 是视频标准 |
| yuv420p | 视频的像素格式，手机和微信只认这个 |
| faststart | 让视频边下边播的设置，网页和小程序需要 |
| 关键帧拼图 | 从片子里均匀截 9 张图拼成一张，一眼看全片版面 |

## 七、命令速查

```bash
npm run video:lint -- <稿件>                 # 配音前：查以前读错过的写法、数字、英文、长句
npm run video:lint -- <配音文本> --tts        # 送进配音模型的最终文本：数字、符号直接算错
npm run video:final -- <成片.mp4> --platform douyin --srt <字幕.srt> --sheet out/sheet.jpg
                                             # 成片体检 + 9 格拼图
```

稿件支持 `.md`、`.txt`、`.json`、`.mjs`（取 `say`、`beats`、`vo` 等口播字段）、`.srt`。
