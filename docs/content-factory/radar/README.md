# 演讲雷达 · 每周一扫一遍人物池

每周一早上自动跑一次（北京 / 新加坡时间 9:23），把人物池里的人**过去 14 天**有没有新的深度内容扫一遍，写成一份周报。

- 人物池和收录标准：[`../people.md`](../people.md)（以 `main` 上的版本为准，`main` 上没有就用 `claude/dazzling-mayer-ykt7px` 分支的）
- 周报存放：`content-radar` 分支的 `docs/content-factory/radar/<日期>.md`
- 只收**深度内容**：30 分钟以上的演讲、长访谈、播客，公开信、备忘录、年会实录、季报里成段的观点。新闻快讯、二手金句、持仓变动不算（持仓变动只在「备注」里提一句）。

## 周报格式

```markdown
# 演讲雷达 · 2026-10-26（覆盖 10-12 至 10-25）

## 本周首推（最多 2 条）
### 人物 · 场合
- 时间 / 形式 / 时长：
- 原始出处：链接（尽量是官方或完整版）
- 全文稿或字幕：有 / 没有 / 部分（链接）
- 一句话要点：
- 建议钩子（二选一句式）：
- 章节草案：01 … / 02 … / 03 … / 04 … / 05 …
- 风险：合规、出处、争议

## 全部新内容
| 人物 | 日期 | 场合 / 形式 | 时长或篇幅 | 深度 1–5 | 链接 | 一句话要点 | 上周报过？ |

## 本周没有新内容的人
姓名列表

## 备注
值得关注但不够深度的动态；建议新增或移出人物池的人（说明理由）
```

## 规矩

- **不编造。** 日期、场合、原话都要有可点开的出处；拿不准的标「待核实」。搜不到就写「没有」，不凑数。
- **去重。** 先看 `radar/` 下之前的周报，报过的只在表里标「上周报过」。
- **合规。** 不出现买卖建议、目标价、收益承诺；持仓只当背景。
