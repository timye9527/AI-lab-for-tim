# 格式拆解 · 「多棱镜」式 10 分钟中视频

> 基于《李录哥大演讲：你是目标还是代价？》的结构（按观看描述整理，原片未逐帧核对）。

## 它为什么能让人看完

| 设计 | 作用 |
|---|---|
| **主钩子是二选一提问**：「你是目标还是代价？」 | 观众一上来就被迫给自己归类，想知道答案就得看下去 |
| **主钩子常驻画面顶部** | 每一趴都在回答它的一部分，注意力被反复拉回来 |
| **章节进度条**：01 六条原则 / 02 神的 IPO / 03 目标代价 / 04 用筷子的人 / 05 教堂赌场 | 观众知道一共几段、现在到哪，不确定感低，就不容易划走 |
| **章节名都是怪词**：「神的 IPO」「用筷子的人」「教堂赌场」 | 每个章节名本身就是一个小钩子，看到进度条就想知道下一段讲什么 |
| **开场先交代「凭什么听他」** | 李录的经历和战绩是可查的史实，先建立信任，后面观点才有分量 |
| **结尾 12 条金句墙** | 适合截图、收藏、转发，收藏率高会带来推荐 |
| **PPT 加轻动画，不露脸** | 制作成本低，可以量产；信息密度高，不靠人设 |

## 时间轴模板（8～10 分钟）

| 段落 | 时长 | 画面 | 口播要点 |
|---|---|---|---|
| 0 · 钩子 | 0:00–0:30 | 大标题二选一提问 + 进度条整体亮相 | 抛出问题，给一个最反常识的结论片段，但不给答案 |
| 1 · 凭什么听他 | 0:30–1:30 | 人物卡：照片、三条可查的履历和战绩、本次场合 | 只讲史实，每条带出处 |
| 2～6 · 五趴正文 | 每趴 1:20–1:40 | 章节卡 → 论点 → 原话卡 → 图解或对比 → 回扣主钩子 | 每趴只讲一个论点，结尾一句话预告下一趴 |
| 7 · 金句墙 | 最后 0:40 | 12 条金句依次浮现，最后整屏停留 3 秒 | 不再新增观点，引导收藏 |
| 片尾 | 0:05 | 出处列表 +「仅为观点整理，不构成投资建议」 | — |

## 每一趴的固定结构

```
章节卡（编号 + 怪词标题，1 秒）
→ 一句话论点（大字，2 秒）
→ 原话卡（带出处和时间码；转述要标「据 XX 整理」）
→ 图解 / 对比 / 数据卡（这一步是二创价值所在）
→ 回扣主钩子：「所以你是目标，还是代价？」
→ 预告下一趴
```

## 画面组件清单

做成可复用的 HTML 模板，每期只换文案和数据：

| 组件 | 用途 |
|---|---|
| 顶部条 | 主钩子 + 章节进度条，全程常驻，当前章节高亮 |
| 人物卡 | 头像、身份、三条履历 |
| 章节卡 | 大号编号 + 章节标题 |
| 原话卡 | 引号样式，底部小字出处；转述和原话用两种样式区分 |
| 对比卡 | 左右两栏：A 派 vs B 派、目标 vs 代价 |
| 数据卡 | 一个大数字 + 一行解释 + 出处 |
| 图解卡 | 流程、分层、四象限（例如李录的四类市场参与者） |
| 金句墙 | 12 格网格，逐条点亮 |

## 制作路线

1. **最省事**：剪映 + 固定模板，口播用 AI 配音。适合先跑两三期验证选题。
2. **能量产**：每期一份数据文件（章节、原话、金句），用 HTML / CSS 动画渲染成页面，再用 `playwright-core` 录屏导出 mp4。这和仓库里 `npm run notes` 生成笔记配图是同一套思路，可以复用。
3. 两条路线的脚本格式一致，先走 1，验证有效再投入 2。

## 标题和封面公式

- 「XX 最新演讲：你是 A 还是 B？」（二选一）
- 「XX 和 YY 吵起来了：AI 是 A 还是 B？」（对决）
- 「XX 说的这句话，散户最该听」（单句放大）
- 封面只放：人物 + 二选一问题 + 场合标签（如「哥大演讲」）。不放具体股票名、收益数字。
