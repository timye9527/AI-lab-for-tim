# 内容工厂 · 把大佬的深度内容做成 10 分钟中视频

> 起点：朋友转来的视频号「圈圈的多棱镜」——《李录哥大演讲：你是目标还是代价？》。
> 它把一场 1 小时以上的英文演讲，做成 10 分钟以内、PPT 加动画的中视频，开头抛出钩子，顶部挂章节进度条，结尾给 12 条金句。
> 这个打法能解决的问题是**高质量投资信息的信息差**：散户天天看日内资讯，大佬一年一两次的深度表达反而没人帮他们嚼碎。

## 判断

- **形式能学，养料是门槛。** 格式拆解见 [`format.md`](format.md)，照着做两三期就能上手。真正拉开差距的是「选谁、选哪一场、从里面拎出哪一句」，这要靠财经功底。
- **优先做「真金白银」的投资人。** 他们的观点要用自己的钱验证，比产业创始人更冷静，也更贴近散户和交易者的需求。产业大佬（黄仁勋、马斯克）放进对照组，用来制造冲突。
- **单人解读之外，多做「对决」。** 同一个问题两位大佬结论相反（例如霍华德·马克斯「AI 可能被低估，但别孤注一掷」对杨东公开看空 AI），天然就是「你是目标还是代价」式的二选一钩子。

## 流水线

```
① 人物池 → ② 素材雷达 → ③ 采集全文稿 → ④ 吃透（拆解卡）→ ⑤ 选题判断 → ⑥ 脚本 → ⑦ 制作 → ⑧ 发布复盘
```

| 步骤 | 做什么 | 产出 | 谁来做 |
|---|---|---|---|
| ① 人物池 | 按分类和评分维度维护名单，每季度更新一次 | [`people.md`](people.md) | 主理人判断，AI 补资料 |
| ② 素材雷达 | 盯年度固定节点（股东会、论坛、季报、13F）和常用渠道 | `people.md` 里的日历和渠道表 | AI 每周扫一遍 |
| ③ 采集 | 拿到**完整**全文稿：官方文字稿 > 带字幕视频 > 媒体整理稿；媒体稿至少找两份互相对照 | `topics/<编号>/transcript.md` | AI |
| ④ 吃透 | 填拆解卡：一句话主旨、论点树、原话和时间码、数据核查、反常识点、和其他大佬的冲突、对散户的行为层面含义 | `topics/<编号>/拆解卡.md` | AI 初稿，主理人改 |
| ⑤ 选题判断 | 按钩子强度、时效、信息差、合规风险打分，过线才做 | 选题卡 | 主理人拍板 |
| ⑥ 脚本 | 按 format.md 的章节模板写口播稿，标出每页画面 | `topics/<编号>/脚本.md` | 一个 AI 写，另一个 AI 审 |
| ⑦ 制作 | HTML 动画页 + 配音 + 录屏导出，或用剪映模板 | mp4 + 封面 | AI 出页面，人来剪 |
| ⑧ 复盘 | 看完播率曲线、跳出点、收藏和转发 | 复盘表 | 主理人 |

**GPT 和 Claude 的分工**：不必固定谁写谁做，关键是**一个写、另一个审**。审的那个只做三件事：核对原话和转述有没有混、数字有没有出处、有没有越过合规红线。

首批选题见 [`topics.md`](topics.md)。脚本怎么写见 [`爆款结构.md`](爆款结构.md)。每周一的演讲雷达见 [`radar/`](radar/README.md)。

**生产线已经搭好**：见 [`../../factory/README.md`](../../factory/README.md)。第一期《李录哥大演讲》的脚本、拆解卡在 `factory/episodes/001-lilu-columbia/`，`npm run video` 一条命令出片。

## 合规红线（视频号 / 抖音 / 小红书通用）

沿用 [`../LAUNCH-CN.md`](../LAUNCH-CN.md) 第 5 节，并补充：

1. **讲「他怎么想」，不讲「他买了什么你也买」。** 13F 持仓、季报重仓股这类素材只用来说明思路，不做「跟着大佬买」，画面里不出现买卖建议和价位。
2. **不预测点位和涨跌。** 大佬的判断可以转述（「付鹏认为 2026 年是 AI 的证伪之年」），但我们不加「所以接下来会涨 / 跌」。
3. **原话和转述分开标。** 原话要有出处和时间码；媒体整理稿里的话一律标「据 XX 整理」。这和测试项目里 `fact` / `quote` 的规则是同一个原则。
4. **二创不搬运。** 以解读、结构化、对比为主，原视频片段只做短引用并注明来源。海外视频不要整段配中文音搬运。
5. **账号单独做。** 不和韭菜段位测试账号混发、互相导流。
6. 每期片尾保留「仅为观点整理，不构成投资建议」。
