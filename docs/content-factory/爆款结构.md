# 爆款结构 · 深度内容怎么写才能让人看完、转走

> 主样本：「圈圈的多棱镜」《李录哥大演讲：你是目标还是代价》（视频号，10:41，截图时 4341 赞、1.2 万转发、2212 收藏）。开头文案来自主理人转述。
> 通用方法来自公开的创作者经验文章（见文末），多是经验总结而不是对照实验，当作起点，用我们自己的数据去验证。

## 速查卡（说「按爆款结构」就照这个写）

```
冷开场（原话 + 说话时的场景）→ 插话/细节 → 共鸣桥（翻译成观众自己的经历）
→ 时空定位（几月几日、哪里、什么场合）→ 传承链（3–4 个年份，不念履历）
→ 观看框架（他讲了什么、我们怎么看、预告最出圈的那句）
→ 五章：原话 → 解读 → 落到你身上 → 挂下一章的钩子（最出圈的放 2/3 处）
→ 12 条金句墙 → 回扣开头的问题，引导评论 → 免责声明
```

主钩子是一个二选一问题，常驻标题栏；五个章节名都用让人想点开的怪词。写稿流程见 `.claude/skills/viral-script/SKILL.md`，出片前必过 `.claude/skills/video-qc/SKILL.md`。

## 一、原片开头逐句拆

| # | 原片在做什么（按转述整理） | 作用 | 我们第一版的问题 |
|---|---|---|---|
| 1 | **场景 + 原话**：李录讲到中国经济时，对台下说了一句话——「你总得知道自己到底是目标还是代价」 | 冷开场。先给全片情绪最高的一句，而且交代「在什么时候、对谁说的」，原话就有了画面感 | 第一版只交代了「在哪说的」，没有「讲到什么时说的」 |
| 2 | **插话**：他还插了半句，「相信在座来自中国的各位都会有很深的共鸣」 | 人物的小动作。真实的细节比概括更可信，也把台下的中国听众和屏幕前的观众连起来 | 完全没有 |
| 3 | **共鸣桥**：这几年家里房子跌过价的人，都听得懂这个「代价」 | **最关键的一句。**把抽象的「代价」换成观众自己的经历，观众从「听别人讲」变成「在讲我」，这也是转发的动机 | 完全没有，这是第一版最大的差距 |
| 4 | **时空定位**：这是 10 月 5 日的纽约，哥伦比亚商学院，第 36 届格雷厄姆与多德年度论坛 | 短句、电影感。情绪拉满后马上落到具体时间地点，让人信 | 有，但放在了钩子后面的说明里 |
| 5 | **传承链**：92 年前格雷厄姆和多德在哥大写出《证券分析》→ 1950 年巴菲特冲着格雷厄姆考进哥大 → 1993 年李录听巴菲特演讲入行 → 30 多年后主讲人轮到了他 | 不念履历，用一条「一代传一代」的线建立权威，自带宿命感。每一环都是可查的史实 | 第一版用的是「人物卡 + 履历」，信息对但没有故事 |
| 6 | **观看框架**：原则只讲了几分钟，其余时间都在拿原则看 AI、美股、中国和世界秩序 | 告诉观众这期怎么看：原则是尺子，后面是量。观众心里有了结构，就不怕长 | 第一版用一页章节预告来做，像 PPT 目录，不像讲故事 |
| 7 | **快速进入正文**：六条原则，前三条来自格雷厄姆：买股票就是买公司，市场先生为你服务…… | 原则一笔带过，不展开，因为它只是尺子 | 第一版在原则上花了两分多钟 |

**一句话总结：** 原片的前一分钟走完了「情绪 → 共鸣 → 可信 → 权威 → 框架」，每一句都有一个明确的任务，没有一句是在「介绍」。

## 二、可复用的结构模板（10 分钟深度解读）

```
0:00  冷开场      全片最有张力的一句原话 + 说话时的场景
0:15  插话/细节   一个人物的小动作或台下反应
0:25  共鸣桥      把这句话翻译成观众自己的经历（房子、账户、工作、孩子）
0:35  时空定位    「这是 X 月 X 日的某地，某场合」，短句
0:45  传承链/来历 用 3–4 个年份串起来，说明为什么值得听他（不念履历）
1:10  观看框架    这场讲了什么、我们怎么看；埋一个开放问题（「有一句话后来传得最广，放到后面讲」）
1:30  第 1 章     尺子 / 背景，快
      ……         每章：原话 → 解读 → 落到你身上 → 一句话挂到下一章
6:30  第 4 章     全片最出圈的一段放在约 2/3 处（多数人看不到结尾）
8:30  金句墙      12 句，截图收藏
9:30  回扣        回到开头那句话，把问题抛给观众，引导评论
```

## 三、每一章都要遵守的四条

1. **用「但是」「所以」连段落，不用「然后」。** 《南方公园》编剧的老规矩：如果两段之间只能填「然后」，这段就是平的。比如：「AI 是工具 → **所以**得回答钱怎么赚 → **但** AI 的每个用户都有成本 → **所以**很难照搬互联网的高利润」。
2. **每章结尾挂一个钩子到下一章。** 「AI 量完，他把尺子转向了中国，也就是开头那句话。」观众每 1–2 分钟就会被重新拉一次，大约对应创作者文章里常说的「每 60–90 秒给一个新刺激」。
3. **原话之后必须有「落到你身上」。** 不是总结他说了什么，而是问观众：你手里的企业是哪一边？你的追涨杀跌是不是在给赌场交门票？这一句决定转发。
4. **最精彩的放在 2/3 处，不放在最后。** 「用筷子的人」在 6 分多钟出现；开头已经预告过，观众是带着期待等到这里的。

## 四、钩子句式库

| 类型 | 句式 | 例子 |
|---|---|---|
| 二选一 | 你是 A，还是 B？ | 你是目标，还是代价？ |
| 场景原话 | 讲到 X 时，他停下来说了一句 | 讲到中国经济，他停下来，对台下说了一句话 |
| 共鸣桥 | 这几年 X 过的人，都听得懂 Y | 这几年房子跌过价的人，一听就懂什么叫代价 |
| 反常识 | 大家都觉得 X，他偏说 Y | 都在追 AI，他说硅谷在卖一场造神的 IPO |
| 预告悬念 | 有一句话后来传得最广，放到后面讲 | 关于筷子的那句话 |
| 数字承诺 | X 分钟讲清 / Y 句话收藏 | 12 句话，截图收藏 |
| 传承宿命 | X 年前……Y 年后，轮到了他 | 三十多年后，台上的主讲人轮到了他 |

## 五、不要做的

- 不要开场先自我介绍、先说「今天我们来聊」。
- 不要用章节目录页当钩子：目录是给已经决定看的人用的，钩子是给还没决定的人用的。顶部章节栏已经承担了目录的作用。
- 不要念履历。用一条线、一个细节、一个年份去证明「他值得听」。
- 不要在金句墙后面再加新观点。

## 六、上线后要验证的

在视频号后台看完播率曲线，重点看三个点：**0:30 的留存**（冷开场和共鸣桥有没有用）、**每章切换处有没有掉坑**（章末钩子有没有用）、**2/3 处之后的留存**。转发 ÷ 点赞是这类内容最重要的指标，原片约为 2.8。
