# 玩法设计逻辑

这份文档回答一个问题：**为什么这么设计，才能让人愿意晒、愿意买，而且做一次能反复用。**

## 1. 整个闭环

```
小红书笔记（人物梗 / 段位梗）
   │ 用户被「测出 XX 型的人，都……」戳中
   ▼
商品卡（0.99 元兑换码）──下单──▶ 自动发货（兑换码 + 网址）
   │                                  │
   │ 没买的人                          ▼
   │                         测试页：12 题 → 段位卡（免费）→ 输码 → 完整报告
   │                                  │
   │                                  ▼
   │                         用户把段位卡晒到小红书 / 朋友圈 / 群
   │                         卡上写着「小红书搜『韭菜段位测试』」
   │                                  │
   └──────────── 新用户搜品牌词 ◀───────┘
```

**闭环的关键是品牌词「韭菜段位测试」**：笔记里不能放链接，所以所有出口都是「去搜这个词」。账号名、商品标题、段位卡页脚、笔记话题里都要有这个词。

## 2. 结果做成两层：段位负责传播，人格负责付费

| | 段位（6 档） | 人格（16 种） |
|---|---|---|
| 气质 | 自嘲、玩梗（韭菜盒子、渡劫失败老韭菜） | 体面、有共鸣（曹操、司马懿、李白） |
| 满足什么 | 「哈哈这就是我」的分享欲 | 「我到底是什么样的人」的自我探索 |
| 收费吗 | **免费**：段位卡 + 人物名 + 心声金句 | **付费**：完整报告 7 个部分 |
| 作用 | 让人愿意晒，带来新用户 | 让人愿意掏 0.99 元 |

只有自嘲，传播得好但没人掏钱（SBTI 就是免费的）；只有严肃的人格分析，有人买但没人晒。两层叠在一起，两件事都能顾上。

## 3. 为什么用 MBTI 式的四个维度

- **冲 / 稳、独 / 跟、快 / 慢、断 / 扛**，每个维度都对应一个真实的投资行为差异，答题时能感觉到「准」。
- 四个字的代码（如「冲独快断」）方便在评论区**对暗号**，和 MBTI 一样自带社交属性。
- 2 × 2 × 2 × 2 = **16 种人格 = 16 篇笔记选题**，内容矩阵天然就有了。
- 主导维度、共同底色、财商六维，都是从同一份作答算出来的，报告看起来厚实，但不用额外出题。

## 4. 为什么选这 16 位人物

- **认知成本为零**：三国、楚汉、语文课本里的人，一看就懂，不用解释白圭是谁。
- **每个人都有一段跟钱或决策有关的真故事**：鸡肋、破釜沉舟、纸上谈兵、乐不思蜀、两根灯草……这些故事本身就是梗。
- **搭子和天敌能形成话题**：曹操 vs 刘禅、项羽 vs 张良、刘邦和张良是搭子。用户会 @ 朋友来测。
- **史实有出处，心声是编写的**：涨知识，又不会被挑错。

## 5. 定价 0.99 元

- 低于「要不要想一想」的门槛，被笔记戳中就顺手买了。
- 销量数字本身就是信任。参考的那款卖了 7.7 万单。
- 后续加价款（还没做）：9.9 元的「双人契合度」，两个人都得测，自带拉新。

## 6. 内容即产品：一份配置，同时生成测试和笔记

`public/tests/jiucai/config.js` 一份文件同时决定三样东西：

1. 测试网页上的题目、结果和报告；
2. `npm run notes` 生成的 23 篇笔记配图和文案：1 篇总览、16 篇人物、6 篇段位；
3. 商品主图、详情图和上架文案。

改一个人物的文案，网页、笔记、商品图同时更新。**这就是「资产化」的含义**：新出一套测试就是新写一份配置，商品、笔记、海报会跟着全部生成。

## 7. 看数据，决定下一步

服务器每天按北京时间累计 5 个数（不记录任何个人信息）：

| 指标 | 含义 | 偏低时怎么办 |
|---|---|---|
| 打开 → 开测 | 开场页有没有吸引力 | 改开场标题 |
| 开测 → 测完 | 题目是否好玩、是否太长 | 删减或改写无聊的题 |
| 测完 → 存卡 | 段位卡值不值得晒 | 改段位名和描述，让它更好笑、更想晒 |
| 测完 → 解锁 | 付费墙说服力（只算从店铺来的人） | 改付费墙的权益文案 |
| 新码使用 vs 店铺订单数 | 买了但没用的人多不多 | 优化发货说明 |

小红书后台还能看到：笔记 → 商品页的点击率、商品页 → 下单的转化率。把两边的数放在一起，就能判断问题出在笔记、商品页还是测试本身。

## 8. 合规是设计出来的，不是事后补的

- 网页**不收钱**、不登录、不收集个人信息。钱只在小红书内流转，网页只负责交付。
- 笔记、商品页、段位卡上**没有链接、二维码、微信**。网址只出现在付款后的自动发货内容里。
- 内容只讲行为习惯，**不碰**个股、点位、涨跌和收益截图。`npm run check` 和 `npm run notes` 会自动扫描高危词。
- 题目里的盘面情境都是虚构的、泛化的。

## 9. 复利：下一套怎么出

同一个引擎 + 新配置 = 新商品 + 新的一批笔记。可以做的方向：
- 打工人搞钱段位
- 粤语段位（配合粤语学习网站）
- 节气 / 节日限定版

每一套的成本是一份配置文件，加上 `npm run check` 和 `npm run notes` 跑一遍。
