# 给 Codex 的任务：韭菜段位测试 · 存笔记草稿 / 准备商品

> 可直接粘贴为 Codex 任务。工作目录是解压后的「韭菜段位测试素材包」。每次运行先看 `进度.json`，只做还没做的一步，做完写回。

---

你在帮主理人把「韭菜段位测试」挂到他已登录的小红书账号和店铺上。**只存草稿、只保存商品不提交，任何「发布 / 提交审核 / 上架」都等主理人确认。**

**第1步：存第一篇笔记草稿**（`进度.json` 的 `drafts` 里没有 `01-结果实拍` 时）
- 创作者后台 → 发布笔记 → 上传图文，按 `笔记/01-结果实拍/` 的 01→06 顺序上传。
- 标题、正文、话题从同目录 `文案.txt` 原样复制。商品卡：店铺里已有「韭菜段位测试」商品时挂上，没有就先不挂，并在 `进度.json` 记一句。
- 点「暂存 / 存草稿」，只存一次；到草稿箱确认存在。写入 `drafts`。

**第2步：准备商品**（`进度.json` 里 `shop_ready` 为真、`product_saved` 为假时；`shop_ready` 由主理人在部署好服务器、填好网址和统一码后设为真）
- 店铺后台新建商品：标题、价格、详情从 `商品素材/上架文案.txt` 复制；主图 `01.png`，详情图 `02`～`06`。
- 发货方式选虚拟商品自动发货：发货链接 = `进度.json` 的 `url`，发货说明 = `上架文案.txt` 里那段（把 `【统一码】` 换成 `进度.json` 的 `code`）。
- **只保存，不提交审核。** 写入 `product_saved: true`，告诉主理人去预览。

**第3步：后续笔记草稿**（主理人发布了第一篇之后，每次最多存 1 篇，草稿箱里待发的不超过 2 篇）
- 顺序：`00-总览` → 人格篇（曹操、刘禅、司马懿、诸葛亮、李白优先）→ 段位篇。

**不做**：不点发布、不提交审核、不删帖、不改账号资料、不回复评论私信、不输入或保存密码和 Cookie；笔记里不加网址、二维码、微信。做不到的写进 `进度.json` 的 `blockers`。
