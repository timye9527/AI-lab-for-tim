# 第二轮：风格与时长

## 第一轮的反馈

- 画风太怪：人物像人偶，大头、没有描边、不像 Tim。
- 配音有口音、有点呆，要正常普通话、偏温暖的男声。
- 去掉呆毛。
- 参考 Tim 本人照片，适度动漫化；整体参考俱乐部 PPT 的色调和风格。
- 先定风格，再出短样片，最后出完整版。
- 重新评估总时长，能讲清楚剧本的前提下再考虑压缩。

## 流程

1. **定风格**（本轮）：静帧、角色、配色、配音候选、总时长。
2. **动态样片**：按定好的风格重做开场约 10 秒。
3. **完整版**：约 70 秒，带字幕 / 无字幕两版 + 封面。

## 总时长：建议约 70 秒

用离线 TTS 把七幕旁白全部合成，实测纯说话时间 54.3 秒：

| 幕 | 旁白 | 建议时长 | 时间 |
|---|---|---|---|
| 一 密码门前的逃兵 | 6.5 秒 | 10 秒 | 0:00–0:10 |
| 二 命运的第二次敲门 | 5.9 秒 | 7.5 秒 | 0:10–0:17.5 |
| 三 颤抖的第一次 | 9.0 秒 | 10 秒 | 0:17.5–0:27.5 |
| 四 人生按下暂停键 | 6.6 秒 | 8 秒 | 0:27.5–0:35.5 |
| 五 一个不太靠谱的会长 | 9.1 秒 | 10.5 秒 | 0:35.5–0:46 |
| 六 我们一起，搞了场大的 | 10.4 秒 | 11.5 秒 | 0:46–0:57.5 |
| 七 那扇门，终于不再陌生 | 7.0 秒 | 12.5 秒 | 0:57.5–1:10 |

加上句间停顿和不说话的笑点（警报、乌鸦、开门、皇冠、合照定格、片尾字幕），合计约 70 秒，在 55–75 秒范围内。压到 60 秒需要删掉约五分之一旁白或提高语速，会损失结尾的温暖节奏，所以不建议。如需 60 秒短版，可以另出剪辑版，优先删画面能讲清楚的句子（「他们只是一次次鼓掌」「没想到……」）。

## 画风

- 俱乐部插画风：粗描边、平涂、一层赛璐璐暗部，PPT 里的四角星做装饰。
- 人物 6 头身，眼睛带适度的动漫高光。
- Tim 按照片设计：两侧推短、顶部往上抓的黑短发，小麦色皮肤，笑起来露牙，偏瘦；开头藏青外套 + 双肩包，后来米色宽松 T 恤。去掉呆毛。
- 配角用同一套画法换发型、肤色、衣服，全部虚构。
- 沿用《把時間拿回來》的柔光、颗粒、顺滑运镜和克制的字幕排版。

配色（取自 PPT 和 EOE 标志）：藏青 `#1B355C`、砖红 `#C15145`、奶油 `#FAF3D7`、长春花蓝 `#B2C3F7`、橙 `#E8763A`、标志蓝 `#1E9BE9`、标志黄 `#FDB813`。

文件：`dist/v2/frame-door.jpg`、`frame-alarm.jpg`、`frame-warm.jpg`、`character-lineup.jpg`。代码：`src/v2/tim2.js`（角色）、`src/v2/frames.js`（关键帧）。预览：`node scripts/snap.mjs "src/v2/frames.html?f=door" out.png 1080 1920`。

## 配音候选

Kokoro v1.1-zh 的 45 个男声全部用语音识别筛了一遍（咬字准确率、音高、语调起伏），选出 4 个：`dist/v2/voice-97.mp3`、`voice-68.mp3`、`voice-95.mp3`、`voice-86.mp3`。上一版的 58 号已弃用。真人录音仍然是最好的选择。

## 第三、四轮的决定

- 角色改成极简火柴人：所有人同一副身板，伙伴只靠一个彩色配件区分；Tim 的变化靠姿态、动作、发型、领带、墨镜、话筒。代码在 `src/v3/stick.js`。
- 后半段场地：汽车 4S 店的高端展厅会议室（不出现品牌标志）。
- 配音：Tim 本人声音，用他的录音做参考离线合成（`scripts/vo-clone.py`）。录音和合成音频不进公开仓库（`assets/vo-tim/`、`dist/v4/` 已忽略）。
- 第七幕旁白改为：「两年前，他连这扇门都不敢打开。两年后……这里，有了一群温暖、并肩作战的伙伴。」门用最早那扇密码门。
- 第一幕正式样片：`src/v4/`（时间轴 `timeline4.js`、画面 `sample4.js`）。生成：
  `TL=src/v4/timeline4.js OUT=dist/v4/audio.wav npm run audio`，
  `PAGE=src/v4/sample4.html DUR=11.6 FRAMES_DIR=.frames-v4 npm run frames`，
  `FRAMES_DIR=.frames-v4 AUDIO=dist/v4/audio.wav OUT=dist/v4/sample-act1.mp4 npm run encode`。
