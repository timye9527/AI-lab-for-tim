# 《一个社恐的两年奇遇记》制作方案

副标题：误入一家奇葩俱乐部之后……
规格：9:16，1080×1920，30fps，目标约 65 秒（允许 55–75 秒）。

---

## 1. 环境检查结果

| 项目 | 结果 | 影响 |
|---|---|---|
| 之前的「AI 音乐视频」 | 找到的是短片《把時間拿回來》（分支 `claude/loving-albattani-okwtpd`）：Canvas 程序绘制 → 无头 Chromium 逐帧渲染 → ffmpeg 合成；配乐用自写合成器 | **直接复用**：渲染脚本、合成脚本、合成器 `synth.js`、静态服务器 |
| GPU | 无（4 核 CPU，15 GB 内存） | 不能本地跑视频生成模型或 Blender 渲染 |
| AI 视频服务 | 没有任何 API 密钥；网络策略把 fal、Replicate、HuggingFace 都拦了 | 这个环境里**做不了真正的 AI 视频生成** |
| 可用网络 | 只有 npm、PyPI、GitHub | 开源 TTS 模型、字体可以从这里装 |
| 配音 | 微软 Edge TTS 被拦；改用离线开源模型 Kokoro v1.1-zh（Apache-2.0，可商用） | 免费，但不是真人质感，见第 8 节 |
| Tim 的照片 | 所有仓库里都没有 | 角色按文字描述设计，需要你确认长相 |

## 2. 技术路线对比

先说清三种东西的区别：

- **AI 视频生成**：用可灵、即梦（Seedance）等模型，从文字或图片生成视频片段。
- **程序化动画**：角色和场景用代码画出来，每一帧都是真算出来的动作和镜头运动。
- **静态图片剪辑**：几张图加推拉缩放。**本项目不用这条路。**

| | A. 程序化动画（样片采用） | B. AI 视频生成 + 本地合成 | C. Blender 3D |
|---|---|---|---|
| 画面风格 | 2D 矢量卡通 + 电影化光影（轮廓光、景深、泛光、颗粒） | 最接近「3D 动画电影质感」 | 真 3D |
| 角色一致性 | **100%**：同一份代码画每一个镜头 | 最大风险：同一角色在不同片段里脸、衣服、比例会漂 | 好 |
| 喜剧节奏控制 | 精确到帧，动作和音效严格对齐 | 难：每段 5–10 秒随机生成，动作时机靠抽卡 | 精确 |
| 中文字（「非法闯入？！」、群消息） | 精确 | 经常写错，需要后期叠字 | 精确 |
| 修改成本 | 改参数重渲，几分钟 | 重新生成、重新抽卡 | 改模型、重渲染（慢） |
| 本环境能否完成 | 能 | 不能直接调用（需要你在可灵 / 即梦账号里生成，我负责分镜、提示词、剪辑、声音） | 不能（无 GPU，无素材库），工期以周计 |
| 费用 | 0 元 | 约 200–500 元（见下） | 0 元，但人工时间最长 |

**推荐：全片走路线 A。** 理由：这部片子的笑点全靠时机（停顿、心跳、乌鸦叫的那一拍），而 Tim 必须在 7 幕里长得一样，这两点正是 A 的强项、B 的弱项。
画面上的代价是：它是**有电影光影的 2D 卡通**，不是皮克斯式的 3D。样片可以直接判断这个风格能不能接受。

如果你坚持要 3D 质感，可以走 B：我出每个镜头的分镜、提示词和角色参考图，你在可灵或即梦里生成，素材交回来后我做剪辑、字幕、配乐、音效和配音。不建议 A、B 混用，风格会打架。

## 4. 角色一致性方案

1. **一份角色定义，全片共用**：`src/tim.js` 里定义了 Tim 的比例、配色、发型、衣服、背包，正面 / 侧面 / 手部特写三种视角。所有镜头都调用它，不会出现「换个镜头换张脸」。
2. **表演靠参数，不靠重画**：眼睛开合、瞳孔大小、眉毛、嘴型、汗珠、腮红、驼背程度、发抖都是参数。早期 Tim 驼背、眼神躲闪；后期把 `hunch`、`worry` 调低就是松弛的 Tim，人还是同一个人。
3. **识别符号**：芥末黄外套 + 深灰双肩包 + 橙色拉链头 + 头顶一撮**呆毛**。呆毛是情绪指示器：紧张时耷拉，惊吓时竖起，开心时翘起。
4. **设定图**：`dist/character-sheet.png`，可以拿给认识 Tim 的人看像不像。
5. **配角**：第二阶段写一个「朋友生成器」，用同样的画法、不同的身形、发型、肤色、服装，固定 6–8 位常驻伙伴，每人一个识别色，跨镜头同样保持一致。

## 5. 完整分镜与制作计划

时间在原剧本基础上微调（开场为了笑点多给了 2 秒），总长约 66 秒。

| 幕 | 时间 | 画面要点 | 声音 | 复用 / 新做 |
|---|---|---|---|---|
| 一 密码门前的逃兵 | 0:00–0:11 | **样片已完成**（见第 6 节） | 悬疑拨奏 → 心跳 → 警报 → 磁带刹车 → 蟋蟀、乌鸦 | — |
| 二 命运的第二次敲门 | 0:11–0:18 | 同一机位，「几天后」。一位伙伴熟练按密码，Tim 特工式潜行跟在后面（踮脚、贴墙）。门一开，暖光、笑声、掌声涌出来，画面从冷色切到暖色；Tim 愣住，笑了。弹出「当场入会！」 | 潜行拨奏 → 开门声 → 掌声和笑声 → 游戏通关音效 | 复用门口全景、Tim；新做：室内全景、伙伴 ×6、冷暖切换 |
| 三 颤抖的第一次 | 0:18–0:27 | 聚光灯下，稿子像电动牙刷一样震，麦克风也抖，整个画面跟着轻颤；台下有人憋笑，然后鼓掌。三次上台快速切换，站姿一次比一次直 | 稿纸震动声、掌声越来越热 | 新做：舞台、讲台、观众席 |
| 四 人生按下暂停键 | 0:27–0:35 | 抱纸箱站在写字楼门口，画面变灰，字幕「工作没了。人生 GAP 3 个月。」公园长椅发呆；手机狂弹群消息「周四来不来？」「缺个主持！」「活动谁来搞？」；一只巨大的卡通手从画外把他拽走，画面恢复彩色 | 音乐几乎停掉，只有风声和通知声；被拽走时「嗖」 | 新做：写字楼、公园长椅、手机界面、巨手 |
| 五 不太靠谱的会长 | 0:35–0:45 | 天上掉下一顶巨大的皇冠盖住眼睛。快速蒙太奇：拿流程表协调、台上忘词挠头、被调侃单身摊手、聚餐偷瞄账单、爬山露营、万圣节奇装异服、不太正规的比赛笑成一团 | 欢快、跳跃，每个切点一个鼓点 | 新做：7 个小场景（每个约 1.3 秒，可以简化背景） |
| 六 一起搞了场大的 | 0:45–0:55 | 两周年庆筹备：设计海报、搬物料、布置舞台、调音响，Tim 在人群里忙前忙后；灯亮、掌声、拥抱；餐桌举杯；镜头缓缓推近 Tim 的脸，一个很自然的笑 | 欢快转温暖（拨弦吉他 + 钢琴） | 新做：会场、餐桌；伙伴全员 |
| 七 那扇门不再陌生 | 0:55–1:06 | **回到开场同一机位**。Tim 没犹豫，按密码，门开，暖光打在脸上，门后是两年来的伙伴：招手、大笑、举相机、喊他过来。镜头从身后升起，大家组成合照，定格。字幕「EOE 中文演讲俱乐部 / 自由开放 · 趣味奇葩 / 第三年，继续一起玩！」 | 开门声 → 开场的拨奏动机换成温暖的大调 → 余韵 | 复用门口全景（开场 / 结尾呼应）；新做：合照构图 |

配音沿用剧本原文。需要调整的只有一处：第一幕最后一句改成「于是，他跑了。」（TTS 单独念「他跑了」会念成「他跑累」，改动后识别正确）。换真人配音后可以改回原文。

**第二阶段工期估算**（确认样片后）：配角生成器和室内场景约 1 天，第二至七幕每幕半天到 1 天，声音和整体调色半天。渲染全片约 9 分钟。

## 6. 开场样片

| 镜头 | 时间 | 画面 | 声音 |
|---|---|---|---|
| 1 密码锁特写 | 0.00–1.75 | 青光密码锁「请输入密码」，Tim 发抖的手指慢慢伸进来，在「5」上方犹豫；镜头微微倾斜推进，每次心跳画面跟着一跳 | 电流嗡嗡声、悬疑拨奏、心跳；配音「两年前，Tim 第一次来到 EOE。」 |
| 2 门口全景 | 1.75–3.70 | 夜晚，冷蓝色。玻璃门上贴着 EOE 的纸，门缝漏出一点暖光（伏笔）。Tim 伸着手指僵住，回头张望两次，路灯上一只乌鸦盯着他 | 回头时「嗖嗖」；三全音颤音弦乐渐强 |
| 3 反打近景 | 3.70–5.35 | 从密码锁的视角看 Tim：眼珠左右乱转，汗珠滑下，咽口水；手指冲着镜头越伸越近、越来越虚 | 木鱼「嗒嗒」配眼珠；「咕嘟」；心跳加速；配音「因为不敢按密码……」；渐强噪声后留 0.15 秒空白 |
| 4 警报幻想 | 5.35–7.35 | 画面炸红：旋转红光、两个警灯、顶光打下来；「非法闯入？！」警示牌从天上砸下来；Tim 尖叫跳起、炸毛、呆毛竖起、悬在半空发抖 | 冲击鼓 + 管弦齐奏、警笛、滑哨、金属牌砸地、鼓点；最后**磁带刹车**，声音被拧停 |
| 5 切回现实 | 7.35–8.30 | 什么都没发生。Tim 还保持伸手的姿势，头发慢慢塌回去；「嘎——」乌鸦叫，他眼珠一斜，尴尬地笑，嘴角发颤、脸红、汗珠滑下 | 只有蟋蟀；乌鸦一声 |
| 6 门口全景（结尾呼应机位） | 8.30–10.95 | 收回手指、踮脚晃两下假装没事、转身、僵硬地走，然后蓄力、一溜烟跑出画面（速度线 + 扬尘）；乌鸦扭头目送；红色印章「第 1 次尝试 · 撤退！」 | 每一步配一个下行拨奏音、弹簧声、嗖、急促脚步、第二声乌鸦叫；8-bit 失败音效；配音「于是，他跑了。」 |

和剧本相比的处理：

- 剧本里「Tim 左顾右盼」放在全景，「伸手准备按」放在特写和反打，让同一个犹豫在三个机位里递进。
- 加了印章「第 1 次尝试 · 撤退！」和 8-bit 失败音效，给第二幕的「当场入会！」+ 通关音效埋了游戏化的伏笔。
- 开场全景和结尾全景用同一个机位（`film.js` 里的 `WIDE`），第七幕直接复用。

## 7. 样片自检（按需求第八节）

| 角度 | 自评 | 说明 |
|---|---|---|
| 故事：看得懂为什么离开吗 | 能 | 伸手 → 犹豫 → 幻想被抓 → 现实里什么都没有 → 尴尬 → 撤退，配音也点明「不敢按密码」 |
| 喜剧：密码门够夸张吗 | 够 | 警报段是全片最大的反差：红光、警示牌、炸毛、悬空发抖，然后磁带刹车切到蟋蟀声。乌鸦和印章补了两个小笑点 |
| 角色：像害羞的普通年轻人吗 | 基本像 | 驼背、躲闪、发抖、脸红，没有英雄感。**但还没和 Tim 本人对过长相** |
| 画面：动画电影质感，不是 PPT | 是动画，不是 3D | 每一帧都是真动作：手指颤抖、走跑循环、镜头推拉跟拍、手持晃动、景深、轮廓光、泛光、颗粒。风格是 2D 卡通 |
| 节奏：前 3 秒抓人吗 | 较好 | 第 0 秒就是发光的密码锁 + 发抖的手指 + 心跳；1.75 秒切全景 |
| 声音：协调吗 | 基本协调 | 整体响度 −14 LUFS、峰值 −0.9 dBTP，符合短视频平台；配音出现时音乐自动让位。**弱点是配音**（见下） |
| 技术：能播放吗 | 能 | H.264 High + AAC，faststart；没有闪烁或变形；字幕已检查不重叠；警报段没有全屏频闪（只在开头和撞击各闪白 1–2 帧） |

## 8. 已知问题和局限

1. **配音是最大短板。** 离线 TTS 的语气偏平，没有「朋友讲糗事」的松弛感；英文「Tim」偶尔发得不够清楚（用语音识别模型反复检查过，大部分情况能识别成 Tim 和 EOE）。**强烈建议换成真人朋友录音**，最贴题，也不花钱。
2. **不是 3D。** 想要皮克斯式质感只能走路线 B，并接受一致性和花费上的代价。
3. **音乐是合成器做的。** 前段的拨奏和警报效果很好；后半段需要温暖的钢琴和吉他，合成器能做但不如真乐器，可以考虑授权一首配乐。
4. **只按文字设计了 Tim 的长相。** 发型、有没有戴眼镜、脸型等需要你确认。

## 9. 需要你确认的事

1. 样片的画风能接受吗？全片走路线 A，还是改走 B（花钱、你来生成素材）？
2. 配音：继续用 TTS，还是找朋友录真人旁白？
3. Tim 的长相：需要改发型、加眼镜、换衣服颜色吗？如果你愿意提供一张 Tim 本人的照片，我只用来调整角色设计，不会出现在片子里。
4. EOE 的真实细节：有没有 logo、代表色、活动的固定日子、两周年庆的真实场景，以及想出镜的伙伴特征（需要本人同意）？
5. 「撤退！」印章 + 8-bit 音效这种游戏化处理，可以贯穿全片吗？
