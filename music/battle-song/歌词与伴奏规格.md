# 《九月九日，与母后Battle》成品歌词 + 练习伴奏规格

> 套唱原曲：陶喆《找自己》（1999《I'm OK》录音室版的结构）
> 用途：音乐脱口秀现场吉他弹唱，目标时长约 4 分钟

**现在以 `song.txt` 为准**：歌词、和弦、弹法、速度、夹品都只改 `music/battle-song/song.txt`。本文件第二、三部分是最初的规格，留作对照，可能和 song.txt 不完全一致。

**生成**：`python3 music/battle-song/make_practice_track.py`（需要 numpy），输出伴奏、歌词时间表和投屏用的 `琴谱.html` 到 `music/battle-song/out/`（不提交）。格式说明见 `music/README.md`。

## 第一部分：给 Claude Code 的任务说明

请根据本文件第三部分的段落表，生成一条**练习用伴奏音轨**，让表演者跟着练节奏和段落衔接。

**要做的**
1. 只生成吉他和弦伴奏 + 节拍器滴答声。**不要生成人声、不要生成旋律**，旋律由表演者自己唱。
2. 输出：
   - `practice_track.wav`：完整伴奏（含开头 1 小节预备拍 4 下滴答）
   - `practice_track_click.wav`：同上，但全程叠加节拍器（每小节第 1 拍重音）
   - `cue_sheet.txt`：每一行歌词的开始时间（分:秒）+ 段落名，方便对着看
3. 参数做成文件顶部的变量，方便改：
   - `BPM = 100`（**暂定值，未经核对**，表演者会自己测原曲速度后修改）
   - `CAPO = 1`（和弦按 C 调指法写，实际发音整体升高 1 个半音）
   - 拍号 4/4

**怎么做（保持简单）**
- 用 Python + numpy 直接合成，吉他音色用 Karplus-Strong 拨弦算法即可，不需要下载音色库，不需要 DAW。
- 和弦按吉他常用开放和弦的音位合成（G、C、D、Am 四个就够），再按 CAPO 整体移调。
- 下面的“弹法代号”对应合成方式：

| 代号 | 含义 | 合成方式 |
|---|---|---|
| 扫 | 正常扫弦 | 每小节 8 个八分音符，节奏 下 下 上 上 下 上，上扫音量略轻 |
| 重扫 | 用力扫弦 | 同“扫”，音量 +30% |
| 轻扫 | 轻扫 | 同“扫”，音量 −40% |
| 闷 | 闷音 | 每拍两下短促下扫，音长极短（约 0.08 秒），音量偏低 |
| 切 | 切音 | 第 1、3 拍正常短扫，第 2、4 拍用短噪声模拟“啪”的切音 |
| 响 | 扫一下让它响 | 只在第 1 拍扫一下，自然衰减到小节结束 |
| 停 | 停扫（说话位） | 整小节静音；带节拍器版本里只有滴答声 |
| 分解 | 分解和弦 | 每拍拨一个音，从低到高循环 |

- 不必追求好听，**能听清小节、段落和停顿位置就算完成**。如果某个效果做起来费时，直接用“扫”替代。

## 第四部分：表演者备忘

- 每次妈妈开口、每次转折，都停扫用说的。停下来是在给观众留笑的时间，不是失误。
- “妈妈妈妈妈妈”这 6 个字用切音，后面的字放开扫。
- 两个“先别挂”的语气不同：第一个咬牙忍住，第二个是好奇、想听下去。
- 试唱时如果某句字太挤，先记下是哪一句，不要当场硬塞。
