# 音乐脱口秀：歌谱、伴奏、投屏琴谱

一首歌一个文件夹，核心只有一份 `song.txt`。歌词、和弦、速度都只改它，下面三样都从它生成：

| 产物 | 命令 | 说明 |
|---|---|---|
| 投屏琴谱 `out/琴谱.html` | `python3 music/songsheet.py <歌>/song.txt` | 大字歌词 + 和弦，按速度自动滚动，可调速、跳句、节拍器 |
| 练习伴奏 + 时间表 | `python3 music/battle-song/make_practice_track.py` | 需要 numpy；同时也会生成琴谱 |

`songsheet.html` 是琴谱网页模板，不绑定哪首歌：直接打开它，把任意 `song.txt` 拖进去也能用。

## song.txt 格式

```
标题：九月九日，与母后Battle
说明：套唱 陶喆《找自己》
速度：100
夹品：1
拍号：4/4

【主歌一】
G C   扫     那天晚上｜视频电话
G C   重扫   我说妈你｜知不知道
Am C         不写弹法默认是扫
-     停     （说）那对象？
> 以 > 开头的是给表演者的提示
# 以 # 开头的是注释，不显示
```

- 每行：**和弦**（每小节写一个，`-` 表示这一小节停扫）、**弹法**（可省略）、**歌词**。小节数就是和弦个数，琴谱滚动和伴奏都按它算时间。
- 弹法：扫、重扫、轻扫、闷、切、响、停、分解。可加修饰，用「·」连：`末1拍停`、`音量0.7`、`渐强0.6-1.3`。
- 「｜」是句中换气，琴谱上显示成空隙。
- 新和弦要出伴奏的话，先在 `make_practice_track.py` 的 `CHORDS` 里补音位；琴谱不受限制。
