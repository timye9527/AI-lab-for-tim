# 06 画风与视觉：「交易终端 × 战报」

分工原则：**口播负责专业，画面负责好懂和好看**。口播里每出现一个术语（4F²、RDIMM、长约、市盈率、熔断），画面上都要有一个 3 秒内看懂的图解。

## 一、整体风格

| 层 | 风格 | 参考感受 | 不要做成 |
|---|---|---|---|
| 主画面 | **深色交易终端**：近黑底、等宽数字、细网格、右上角常驻「板块市值」读数 | 彭博终端、交易室大屏 | 花哨的科技蓝光效、满屏粒子 |
| 叙事层 | **战报**：时间轴上的刀痕、红框圈出的关键日、打字机式字幕 | 战地新闻、案件复盘 | 卡通、表情包 |
| 人物层 | **引语卡**：人名 + 头衔 + 原话（中文译文）+ 来源角标 + 三格可信度 | 法庭证词卡 | 伪造的 X 截图、AI 换脸 |
| 主播层 | 暗色书房 / 客厅，暖光，固定机位；只出现在开场后、段落转折和结尾 | 「朋友在跟你复盘」 | 演播室、站在大屏前比划 |

## 二、色彩规则（面向中文观众）

| 用途 | 颜色 | 说明 |
|---|---|---|
| 背景 | `#0B0D10` 近黑 | 全片统一 |
| 上涨 / 红方多头 | `#E5484D` 红 | **红涨绿跌**，按中国习惯，不要用美股的绿涨红跌 |
| 下跌 | `#30A46C` 绿 | 只用在行情数字和 K 线上 |
| 蓝方空头 | `#3E63DD` 蓝 | 只用在「多空分屏」的右半边，不和涨跌色混用 |
| 强调 / 刀痕 / 关键日 | `#FFB224` 琥珀 | 每个画面最多一处 |
| 正文文字 | `#EDEEF0` / 次要 `#9BA1A6` | |

## 三、字体与版式

- 数字：等宽字体（如 JetBrains Mono / Roboto Mono），所有百分比带正负号。
- 中文：思源黑体，标题 Heavy，正文 Regular。
- 每个数字的右下角带来源角标，格式「来源 · 日期」，如「CNBC · 10/15」。
- 竖排免责声明常驻左侧，透明度 60%。
- 横屏 16:9 为主；切竖屏时，上 55% 放图表、下 45% 放字幕和大字。

## 五、节奏和声音

- 画面 3–5 秒一切；「一周五刀」段每一刀用一个低频冲击音，刀与刀之间留 0.5 秒静音。
- 引语卡出现时压低背景音乐，让人物原话（主播念译文）单独站出来。
- 冷开场的心跳底噪在「那两天，到底发生了什么？」后切断，进入第一个画面。
- 全片 BGM 两段：前半段（到第五刀）紧张的电子低音，后半段（长鑫段之后）换成更冷静的钢琴 + 低音，表示「从情绪到分析」。

## 六、红线

- 不用 CNBC、彭博等的直播画面和截图；所有图表自己做，数据来自 `facts.csv`。
- 不伪造社交媒体截图；人物发言一律用引语卡，注明「中文译文」和来源。
- 不用真人头像做表情包；人物只用名字 + 头衔，或者剪影。
- 示意图必须标「示意」。
