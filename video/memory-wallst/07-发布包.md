# 07 发布包：标题、封面、简介、标签、评论区

> 这一期的观众，多数是**这周手里拿着存储、被砸懵了的人**。所以文案只打一个痛点：「我亏了，到底是谁干的，接下来会不会更糟？」
> 打法：**先承认疼（−26%）→ 推翻他以为的答案（不是长鑫）→ 承诺给他判断工具（四个开关）**。
> 红线不变：不出现买卖建议、目标价、股票代码；简介和评论区不放链接、二维码、微信。


### 高频问题的回复口径（频道号统一回复）

| 观众会问 | 回复 |
|---|---|
| 现在该割还是该扛？/ 能抄底吗？ | 不做个股建议哈。视频最后四个开关（美联储、云巨头财报、三星海力士财报、OpenAI 融资）都在两周内，看完再自己判断。 |
| 什么时候反弹？ | 不预测点位。能说的是：这周的大跌主要发生在利率和融资担忧最重的两天，不是长鑫消息当天。 |
| 长鑫真这么厉害？ | 长期是真威胁（全球第四、约 8% 份额、300 多个 4F² 专利族），但产品还没公布速度、容量、良率，计划里也没有 HBM。高盛和 Counterpoint 都认为 2028 年前影响有限。 |
| 是不是 AI 泡沫破了？ | 台积电同一天还说 AI 需求大于供给。市场担心的不是需求，是「谁来付钱」——这正是视频的核心。 |
| 你是谁的托 / 收了钱吧 | 每个数字都有出处，简介里列了来源和日期；视频不推荐任何股票。 |
