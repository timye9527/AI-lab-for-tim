# 03 前 30 秒与留存设计

长视频的完播靠两件事：**前 30 秒留住人**，**之后每 60–90 秒给一个「再看一会儿」的理由**。

## 一、前 30 秒的三个检查点

| 时间点 | 观众在想什么 | 本片怎么接 |
|---|---|---|
| 第 0 秒（首帧） | 「这是什么？」——还没开声音就要看懂 | 首帧大字：**卖内存条的，毛利率快追上茅台了**。反差（内存条 × 茅台）+ 中国观众熟悉的锚点 |
| 第 3 秒 | 「跟我有关吗？有意思吗？」 | 第一句就给最大的数字：三个月收入 540 亿美元 |
| 第 8–15 秒 | 「会不会是标题党？」 | 立刻上两个有名有姓的对手：伯里押它腰斩，天才基金经理一个月亏三分之二。有冲突，有人，有钱 |
| 第 24–30 秒 | 「要不要看完？」 | 抛问题「谁是对的？」+ 承诺「四个回合 + 四个信号 + 三个月后对答案」 |

钩子公式：**反差数字 → 两个真人对赌 → 一个悬而未决的问题 → 承诺看完能得到什么**。

## 二、三个开场版本（建议先用 A，切片时 B、C 拿来做 A/B 测试）

**A. 数字对撞（正片用，约 24 秒）**：见脚本冷开场。

**B. 人物悬念（适合切片，约 20 秒）**

> 七月三十号，一个二十多岁的基金经理，
> 把他整本股票持仓，一口气卖给了城堡基金。
> 半年前，他写的文章被叫作 AI 圈的圣经。
> 他重仓的，就是这两年涨得最疯的东西——存储。
> 他错了吗？还是只是早了一步？

**C. 反问体（适合竖屏短视频，约 15 秒）**

> 一家公司刚交出史上最好的成绩单，股价却跌了。
> 三星是这样，SK 海力士也是这样。
> 华尔街到底知道什么，是我们不知道的？

三个版本都只用 `facts.csv` 里已有的事实（F01、F05~F07、F14、F17、F30），不额外加数字。

## 三、全片的「再看一会儿」节点

| 时间 | 手法 | 台词 |
|---|---|---|
| 0:24 | 悬念提问 | 华尔街到底在炒什么？谁是对的？ |
| 1:00 | 承诺 | 三个月后，我们回来对答案 |
| 2:15 | 冲击数字 | 一家公司，想要全世界四成的内存 |
| 2:38 | 转折预告 | 可空头只用一张图，就让这些话没那么硬了 |
| 3:00 | 类比 | 车速还在往上，可油门已经在松了 |
| 3:58 | 反问预告 | 可多头有一个反问，空头很难回答 |
| 5:15 | 打脸 + 预告 | 《寒冬将至》……空头最狠的一刀，还没出 |
| 6:05 | 中国视角 | 长鑫卖得比三星还贵 |
| 6:45 | 人物命运 | 杠杆和时机，把他送下了牌桌 |
| 7:30 | 揭示结构 | 这里面藏着一个圈 |
| 8:00 | 实用价值 | 想自己当裁判，盯这四件事就够了 |
| 9:30 | 互动 + 下期 | 评论区打红或蓝；下期讲筛信息的方法 |

## 四、画面节奏规则

- **左红右蓝分屏是全片的「骨架」**：谁发言谁那边亮，观众不用听也知道现在是哪一方。
- 画面 3–5 秒一切；数字一律大字砸入，带来源角标（如「TrendForce · 2026-09-30」）。
- 每张观点卡带三格可信度图标：信息位置 / 真金白银 / 利益相关。这是本片和别的财经号拉开差距的地方。
- 竖排免责声明全片常驻。

## 五、一稿多用：切出 4 条竖屏短视频

| 切片 | 取自 | 时长 | 开场句 |
|---|---|---|---|
| 天才爆仓 | 开场 B + 第四回合后半 | 约 50 秒 | 七月三十号，一个二十多岁的基金经理…… |
| 利润创新高，股价却跌 | 开场 C + 第二回合 | 约 60 秒 | 一家公司刚交出史上最好的成绩单…… |
| 一家公司要全世界四成的内存 | 第一回合 | 约 45 秒 | 去年十月，OpenAI 一家公司…… |
| 四个信号 | 自己当裁判 | 约 55 秒 | 存储涨到头了吗？盯这四件事就够了 |

每条切片结尾都用同一句：**完整的多空四回合在主页**。
