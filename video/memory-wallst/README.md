## 合规

- 公司只作为行业事实出现；不说「买」「看好」「目标价」，不念股票代码，不推荐基金或板块。
- 观点卡只展示三格图标，不展示分数，避免被理解成「推荐谁」。
- 口播结尾和全片竖排都有「不构成投资建议」。
- 画面、简介不放链接、二维码、微信。
