# 华尔街到底在炒什么？存储多空四回合（10 分钟版）

上一版是 2 分钟的 DRAM / HBM 科普（`claude/ecstatic-planck-vcya5k` 分支 `video/dram-hbm/`），只讲「为什么涨价」，太薄。
这一版升级为 **10 分钟的多空对辩**：红方（多头）和蓝方（空头）各出两张牌，每张牌都带出处和可信度。

一句话主线：**多空吵的不是「存储好不好」，而是「好日子还有多长」。**

## 合规

- 公司只作为行业事实出现；不说「买」「看好」「目标价」，不念股票代码，不推荐基金或板块。
- 观点卡只展示三格图标，不展示分数，避免被理解成「推荐谁」。
- 口播结尾和全片竖排都有「不构成投资建议」。
- 画面、简介不放链接、二维码、微信。
