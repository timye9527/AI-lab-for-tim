# 华尔街到底在炒什么？存储多空四回合（10 分钟版）

上一版是 2 分钟的 DRAM / HBM 科普（`claude/ecstatic-planck-vcya5k` 分支 `video/dram-hbm/`），只讲「为什么涨价」，太薄。
这一版升级为 **10 分钟的多空对辩**：红方（多头）和蓝方（空头）各出两张牌，每张牌都带出处和可信度。

一句话主线：**多空吵的不是「存储好不好」，而是「好日子还有多长」。**

## 工作流（按优先级）

```
① 信息质量  →  ② 脚本  →  ③ 前 30 秒与留存  →  ④ 制作（分镜、图表、配音、剪辑） →  ⑤ SEO 标题、封面、文案
   本次完成        本次完成      本次完成                 额度刷新后                       额度刷新后
```

## 自检

```bash
npm run video:check              # 按今天的日期
npm run video:check -- --prompter   # 顺便重新生成提词器版
node video/memory-wallst/check.mjs 2026-10-30   # 模拟某一天
```

当前结果（2026-10-17）：**定稿 v1.0，通过，可以录**。口播约 9 分 10 秒（加图表停顿约 10 分钟），引用 29 条事实：18 条交叉印证（≥2 个独立来源一致），4 条是公开史实待抽查，7 条单一来源都在口播里加了「据…」限定。

## 合规

- 公司只作为行业事实出现；不说「买」「看好」「目标价」，不念股票代码，不推荐基金或板块。
- 观点卡只展示三格图标，不展示分数，避免被理解成「推荐谁」。
- 口播结尾和全片竖排都有「不构成投资建议」。
- 画面、简介不放链接、二维码、微信。
