# 制作方案 ·《AI省下的钱，被谁赚走了？》

> 4–5 分钟横版二维动画经济科普，16:9，1920×1080，30fps。叙事只依据主理人给的旁白（[口播稿.md](口播稿.md)）。
> 本文件管「怎么做」；逐镜头内容看 [分镜表.md](分镜表.md)，资产和复用次数看 [资产清单.md](资产清单.md)。三份都从 `storyboard.mjs` / `assets.mjs` 来，改分镜只改数据再跑 `node scripts/board.mjs`。

## 一、一页结论

| 项 | 方案 |
|---|---|
| 标题 | 推荐《**AI省下的钱，被谁赚走了？**》（见第二节） |
| 时长 | 旁白 1363 字。按每分钟约 300 字的讲故事语速，**成片约 5 分钟**（估算 5:07，65 个镜头）。时间码以配音实测为准 |
| 结构 | 开场钩子 → 五幕 → 尾声；**三次反转**用同一套「反转语法」强调：反转音 + 0.4 秒定格 + 顶部「反转进度条」亮一格 |
| 画风 | 电影感二维动画（赛璐珞两层阴影 + 轮廓光 + 景深 + 柔光）+ 同色系简洁信息图。头身比约 1:5 的「轻 Q 版」，10 岁和 80 岁都看得懂 |
| 看得懂的办法 | 每个经济概念配一个生活里的东西：利润 = 煎饼、两难 = 跷跷板、固定成本 = 背篓、行业洗牌 = 扑克牌、连锁反应 = 多米诺、算账 = 算盘 |

## 二、标题打磨

原题《AI 让你效率翻倍，为什么钱却被别人赚走了？》19 个字，封面放不下，而且 30 → 12 小时其实是 2.5 倍，「翻倍」不准。

| 方案 | 字数 | 评价 |
|---|---|---|
| **AI省下的钱，被谁赚走了？**（推荐） | 11 | 直接对应全片核心那句「节省下来的钱，并没有全部留在他的口袋里」；有悬念；封面能放两行大字 |
| 效率翻倍，钱去哪了？ | 9 | 更短，但没有「AI」，搜索吃亏 |
| 用上AI，为什么更难赚钱？ | 11 | 戳痛点，但「更难赚钱」对小李不成立，和结尾冲突 |

- 片内标题卡、片尾、封面统一用推荐标题。
- 平台标题可以加副标题：《AI省下的钱，被谁赚走了？一家县城婚庆公司的故事》。
- 封面文案：「省下的钱 / 被谁赚走了？」两行大字 + 小陈、小李隔街对望，金币从小陈这边飘向街对面。

## 三、结构和三次反转

```
00:00 开场钩子 ──── 赚翻了？→ 一年后利润变薄 → 赚钱的人居然不做婚庆 → 标题
00:33 第一幕 ────── 五个人的小公司：多赚钱 = 多招人
01:02 第二幕 ────── AI 来了 ……………… ① 效率提升（30 小时 → 12 小时）
01:43 第三幕 ────── 小李来了 ………………② 降价竞争（一万 vs 七千，小陈跟着降）
02:34 第四幕 ────── 行业洗牌：三种公司、多米诺
03:13 第五幕 ────── 小李转型 ………………③ 模式转型（五十家 × 一千 = 五万服务收入）
04:07 尾声 ──────── 从县城到所有行业：四环总结链 → 两个问题 → 收尾
```

**反转语法（三次一模一样，观众形成记忆）**：
1. 反转前一拍：音乐收一下或抽掉。
2. 反转那一刻：X1 反转音（锣 + 上扬）+ 画面定格 0.4 秒。
3. 顶部「反转进度条」亮一格（片头先出三个空格，告诉观众「后面有三次反转」，是留人的钩子）。
4. 尾声四环总结链的第一环用同一个图标，把三次反转和经济规律串起来。

**数字只当道具**：30 → 12 小时、一万 vs 七千、五十家 × 一千，每次出现都挂虚线框「假设」角标（G24）；资金流只画粗细，标「示意」，不出现百分比、图表出处、「数据来源」这类会被当成真实统计的东西。

## 四、角色设定（全片锁定，不允许漂移）

所有角色都是**参数化代码角色**（写法照微电影的 `tim.js`）：配色、比例、发型写死在一份定义里，表情和动作是参数。下表的颜色值就是代码里的值。

### C1 小陈（婚庆公司老板）

| 项 | 设定 |
|---|---|
| 年龄 / 体型 | 38 岁左右；圆脸、微胖；头身比 1:5；剪影是「圆」 |
| 发型 | 黑色三七分短发，头顶一撮翘毛（远景也能认出来） |

| 项 | 设定 |
|---|---|

## 五、视觉风格

| 项 | 规则 |
|---|---|
| 角色上色 | 赛璐珞：底色 + 一层暗部 + 一条轮廓光（照微电影 `fx.js` 的角色打光）；线条深棕不用纯黑，显得柔和 |
| 背景 | 平涂 + 大块渐变 + 柔光，分 3 层（远 / 中 / 近）做视差；近景虚化，主体清楚 |
| 光线讲情绪 | 清晨金色（开场）→ 白天暖（顺）→ 深夜冷青（AI 出场、压力）→ 黄昏（尾声）。小陈得意时暖，丢订单时冷 |
| 电影感 | 镜头都是缓入缓出的虚拟摄影机；关键时刻临时加上下黑边（C07 剪影、C54 英雄镜头、C64 收尾）；轻颗粒 + 暗角 |
| 动漫感 | 集中线、星星眼、汗滴、头顶冒烟、问号、亮相定格加名牌；夸张但不吵 |
| 信息图 | 和角色同一套颜色；粗圆角线条、纸张底纹；**一镜只讲一件事**，最多 3 个标签 |
| 色板 | 囍红 `#D23A3A`、金 `#E8B04B`、墨 `#2B2B33`、纸 `#F6EFE3`、青绿 `#2BB3A8`、AI 蓝 `#4FD8F0`、夜 `#1E2A44`、警示橙 `#F06A3C` |
| 字体 | 思源黑体（正文、字幕、标签）、站酷快乐体（标题、反转进度条）；都是开源可商用 |
| 字号 | 信息图大字 ≥ 96px、标签 ≥ 56px、字幕 54px；老人在手机上也看得清 |
| 字幕 | 底部居中一行，≤ 20 字，白字深色描边；信息图把画面底部 18% 留空给字幕 |
| 安全区 | 反转进度条放右上角小尺寸；关键文字不放顶部 15%（B 站弹幕区） |
| 画面里的文字 | **全部由代码叠加**，不出现 AI 画的字；店招只写「小陈婚庆」「小李工作室」这类虚构名；手机、电脑界面用通用样式，不出现任何软件标志、二维码、链接 |

## 八、剪辑节奏建议

| 段落 | 时长 | 平均每镜 | 节奏 | 音乐 |
|---|---|---|---|---|
| 开场 | 约 33 秒 | 3～4 秒 | 最快：结果、反转、悬念先给，**前 30 秒不自我介绍、不放目录** | 喜庆唢呐 → 一年后抽掉 → 悬疑拨弦 → 标题鼓点 |
| 第一幕 | 约 29 秒 | 4～5 秒 | 交代人物和烦恼，漫画分格加快信息密度 | 轻快主题 |
| 第二幕 | 约 42 秒 | 4～5 秒 | 越来越爽 → C26 唱片刮擦急停 → C27 悬念 | AI 钢片琴 → 欢快 → 断 → 低音 |
| 第三幕 | 约 51 秒 | 5 秒 | 对手亮相、价签对比、订单飞走；节奏紧 | 小李电子拨弦 + 压迫低音 |
| 第四幕 | 约 39 秒 | 5～6 秒 | 讲道理的一幕，放慢，信息图多留半拍 | 中性、稳 |
| 第五幕 | 约 53 秒 | 5 秒 | 转型、算账、英雄镜头，推到全片高潮 | 拨弦主题升调 → 高潮 |
| 尾声 | 约 60 秒 | 5～6 秒 | 拉远、总结、两个问题，留白给观众想 | 收成一句温暖的主题 |

**通用规则**：
1. 每 6 秒以内画面必须有新变化（新元素、新机位或新动作）；分镜自检会报超过 6.5 秒、又没写出多个变化节点的镜头。
2. 关键数字落地后多停 0.6～1.2 秒（分镜里的 `hold`），让人看清。
3. 切镜跟着口播句读走，不在一句话中间硬切；漫画格、清单类跟着口播节拍逐个亮。
4. 配乐比人声低约 20 dB，有口播时自动再压；反转音之前抽掉音乐半拍，反差才大。
5. 幕名小签只在左下角出 1.5 秒，不单独占时间。
6. 响度 -14 LUFS，真峰值 ≤ -1 dBTP，48 kHz。

**如果一定要压到 4 分 30 秒**（不推荐，会伤故事），可删的句子：「朋友圈文案、客户方案、宣传海报，也能大幅加快制作速度。」「以前这种规模，根本很难跟小陈竞争。」「每天忙着回复客户。」「广告公司、教育培训……制造工厂……」中保留 3 个行业。合计约 70 字，再把语速提到每分钟 310 字左右。

## 九、合规和防错（对照错误档案）

| 风险 | 这期的处理 |
|---|---|
| 假设数字被当真实统计 | 每次出现都挂「假设」角标；资金流只画粗细、标「示意」；口播本来就说「假设」「可能」；片尾写明虚构和假设 |
| 虚构企业 / 采访 | 只有两个虚构人物和虚构店名；不出现真实品牌、App 界面、真实人物；没有采访镜头 |
| 免责声明、AI 标识 | 口播里有「小陈和小李只是两个虚构人物……」；片尾卡写免责声明和「内容由 AI 辅助生成」；发布时勾选 AI 生成标识 |
| 链接、二维码、微信 | 画面、片尾、简介都不放；「朋友圈」只在口播里出现，画面用通用手机界面 |
| 人民币图样 | 金币只画「¥」符号，不画票面 |
| 必须义「得」、句末 AI、多音字 | 稿子已改（见口播稿开头）；读音覆盖表已列；G2 合成后逐句看拼音表 |
| 数字直接送模型 | 送配音前转中文：30 → 三十、12 → 十二 |
| AI 读法 | 13 处 AI 统一按字母读，样片里专门听「利用 AI，」「使用 AI、」这两处紧贴标点的 |
| 孤字、短标签折行 | 标签都 ≤ 6 字；G5 拼图检查 |
| 画面写死时长 | 画面文字不写「这五分钟」之类 |
| 配乐杂音 | 混音前单独导出配乐听 10 秒 |
| 版权 | 音乐全部原创合成；字体用开源可商用的 |
